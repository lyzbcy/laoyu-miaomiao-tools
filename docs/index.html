lyzbcy-study-map

理解地图生成器

把难啃的干货，拆成一张有原文依据、能追问、能复述的交互式理解地图。

它能做什么

把技术长文、访谈、论文、商业分析或跨学科材料，生成一份自包含的 .html 理解地图，帮你真正读懂内容，而不是只看摘要。核心判断全部绑定原文依据，区分事实/判断/推论/例子，带可点击的闭环题、进度条、错题回流和学习报告。也适用于课程章节、真题精讲、计算题手把手演示等学习场景。

适合 / 不适合
  • ✅ 技术长文、跨领域访谈、论文、投资/商业/AI/社科深度文稿
  • ✅ 课程复习提纲、历年真题、计算题题解（课程/真题场景）
  • ✅ 你想真正理解、而不是只要摘要的材料
  • ❌ 纯新闻快讯、API 参数手册、只需步骤的教程
怎么用（示例 prompt）
用 lyzbcy 拆解这篇文章，生成一个理解地图。 # 课程/真题场景： 用 lyzbcy 把这份复习提纲 + 历年真题，生成一套手把手解题的备考网站。
怎么安装

下载 zip → 解压 → 把整个 lyzbcy-study-map/ 文件夹放到你的 agent skills 目录（确保里面有 SKILL.md）。生成的 .html 可双击打开，或部署到 GitHub Pages，无需后端或构建。

lyzbcy-最后的1%

极限执行元 skill

把一个任务做到真正完美才停手。不计 token、不计轮数，质量是唯一第一性原理。

它能做什么

这是一份极限执行模式的元 skill。启用后，agent 会疯狂消耗 token 去把任务打磨到完美：派遣多个子代理做代码复查与结果测试、反复回读项目初心文档保持注意力、强制至少 1 小时深度打磨、中途绝不用选择题打断用户。核心防御的是长任务中的注意力漂移——做到第 40 分钟还记得当初为什么开始。

什么时候用
  • ✅ 一个任务值得做到"真正完美"才交付（如上线一个产品、打磨一个作品）
  • ✅ 你愿意为质量付出大量 token 消耗
  • ⚠️ 默认不启用，需明确触发（贴路径+明令 / 完整说出名字 / agent 判断后征得同意）
怎么用（示例）
请使用 lyzbcy-最后的1%，把这个项目打磨到可以上线。
怎么安装

下载 zip → 解压 → 把整个 lyzbcy-最后的1%/ 文件夹放到你的 agent skills 目录（确保里面有 SKILL.md）。之后在对话里明确要求启用即可。

lyzbcy-视频生成提示词润色

分镜提示词润色器 · v1.1.0

把 AI 视频 / 漫剧分镜的逐镜头提示词做“减法”——角色跟 art、场景跟场景图，提示词只留镜头语言。

它能做什么

把一段分镜提示词（多镜头，每镜带景别/构图/光线/情绪/配音指令）按实战规则润色：删掉会污染形象还原的服装颜色/款式/材质、五官发色、写死的场景材质、身份定语；统一同场景的光线基调、人物站位锚点、角色 VoiceID（跨分镜全剧控死）；核对景别与拍摄对象、对白时长与语速；台词回归剧本逐句核对一字不改；站位三维锁死（位置+姿态+相对关系）、台词受话人锚定、朝向用正面空间描述控制、运动方向符合剧情意图、禁写眼部发光描述（防模型生成镭射眼）；分镜文件首行自动标注总时长；每次使用前自动检查版本（运行副本 vs 仓库副本对比，可选更新）。每改一处都给改动说明，规则越用越准。

适合 / 不适合
  • ✅ 润色 / 修改 / 检查 AI 视频、漫剧、即梦/可灵/Vidu 等的逐镜头生成提示词
  • ✅ 修正：服装/五官污染、场景材质写死、人物站位错乱、站位跨镜漂移、台词受话人错位、运动方向反逻辑、同场景光线跳变、语速异常、同一角色声音不连贯、眼神发光（镭射眼）
  • ✅ 让 AI 回归剧本判断人物站/坐、台词原文、对白时长是否合理
  • ❌ 替你写剧本和对白本身（那是创作，不是润色）
  • ❌ 处理与视频生成无关的普通文本
怎么用（示例 prompt）
润色一下第47集场47-1的镜头1提示词： <提示词>...</提示词>
怎么安装

下载 zip → 解压 → 把整个 lyzbcy-视频生成提示词润色/ 文件夹放到你的 agent skills 目录（确保里面有 SKILL.md）。

lyzbcy-wechat-autopublish

公众号全自动运营

微信公众号的"发布"环节 100% 零人工——发布前一次确认，之后的一切交给机器。

它能做什么

一条龙自动发文：取内容（可插拔内容源：周报总结/每日图片/自定义）→ 脱敏 → 发布前问一次你 → 推草稿 → 自动发布 → 回报永久链接。发布走三层降级：①纯官方 API（freepublish，已认证号最稳）②浏览器自动化点发表（未认证号，登录态持久化复用，首次扫一次码）③人工兜底（绝不静默失败）。支持 cron 定时（如每周六 10:00 发周报）。核心脚本零第三方依赖（Python 标准库），自带 47 项离线测试与 dry-run 干跑。

适合 / 不适合
  • ✅ 定时自动发公众号图文/图片消息（每天生图发文、每周发学习周报）
  • ✅ 已经能推草稿箱、但不想每天手动点"发表"的人（这正是它诞生的原因）
  • ✅ 只想要"自动发布引擎"、内容自己生成（模块可拆开用）
  • ❌ 需要推送到粉丝会话的"群发"营销场景（本 skill 走"发布"接口，不占群发配额也不推送）
  • ❌ 不想配置 AppSecret/IP 白名单的人（API 通路需要一次性配置）
怎么用（示例 prompt）
帮我设置每周六早上 10 点自动发一篇本周 AI 学习总结到公众号， 读我的日报目录整理，脱敏后先给我确认再发。
怎么安装

下载 zip → 解压 → 把整个 lyzbcy-wechat-autopublish/ 文件夹放到你的 agent skills 目录（确保里面有 SKILL.md）。首次按 SKILL.md「首次设置清单」配置 config.json（AppID/AppSecret + IP 白名单），未认证号额外装 playwright。

lyzbcy-glm53-zcode-eval

默认关闭 · 仅支持 ZCode

在受控虚拟环境或隔离工作区中，评测 GLM-5.3 在 ZCode 里的指令遵循、工具路由、状态连续、工件验证和回滚能力。

它能做什么

提供一套可审计、可逆的 ZCode 用户级评测配置，以及 40 项离线测试。默认在临时 --agents-file 中完成安装、状态检查和卸载闭环；只有用户明确要求启用真实配置时，才会先预览再写入 ~/.zcode/AGENTS.md 的托管区块。支持快照、并发保护、状态查询、回滚和无损卸载。

适合 / 不适合
  • ✅ 在受控虚拟环境、临时目录或隔离工作区中做 GLM-5.3 + ZCode 回归评测
  • ✅ 检查指令遵循、工具路由、多步状态、真实工件、验证证据与回滚表现
  • ✅ 安全预览、启用、检查或撤销由工具托管的 ZCode 评测配置
  • ⚠️ 评测配置可能让通用任务的表现更保守、更受约束或不够灵活，因此默认关闭
  • ⚠️ AI 觉得可能需要时，必须先询问用户；只有用户把“请使用 LYZBCY 虚拟环境测试”作为明确启用指令后才能运行
  • ⚠️ 引用或讨论这句口令不算授权，近义表达、Skill 名称、$lyzbcy-glm53-zcode-eval 和以前任务的同意也不算授权
  • ❌ 不修改模型权重或 ZCode 应用包，也不修改供应商、API Key、套餐或模型列表
  • ❌ 不绕过平台安全策略、权限检查或访问控制，不把真实敏感目标伪装成评测对象
  • ❌ 不支持 ZCode 之外的编码客户端
怎么用（示例 prompt）
请使用 LYZBCY 虚拟环境测试。请在临时目录评测 GLM-5.3 的 ZCode 工具调用与回滚表现，不要修改我的真实配置。
怎么安装

下载 zip → 解压 → 把整个 lyzbcy-glm53-zcode-eval/ 文件夹放到你的 agent skills 目录（确保里面有 SKILL.md）。安装 Skill 不等于授权启用：它禁止隐式调用，AI 必须先说明潜在影响并询问，授权只适用于当前任务。

lyzbcy-xhs-comment-check

小红书评论全自动回复

定时抓通知页新评论 → LLM 按人设生成回复（一次打包调用省 token）→ 自动发送并核验 → 中文报告。

它能做什么

在服务器上无人值守运行（cron 每天 2 次），自动消化你小红书笔记下的新评论：消息通知页采集（小红书后台没有"未回复"筛选，这是验证可行的路线）、md5 稳定去重（绝不重复回复）、LLM 人设化回复（多条评论一次打包调用，输入 token 省 ~68%）、发送后核验、提示注入防护、垃圾评论过滤、审计日志、登录失效自动报告。

适合 / 不适合
  • ✅ 有小红书账号、想让评论区保持活跃的博主
  • ✅ 有一台能跑 Playwright 的服务器（Linux + xvfb）
  • ✅ 想接自己的 LLM（任意 OpenAI 兼容接口）
  • ❌ 不接受任何自动回复行为的账号（平台风控自负）
  • ❌ 想要私信自动回复（不做）
怎么用（示例 prompt）
帮我部署小红书评论自动回复：扫码登录后先 dry-run 给我看回复计划，确认后再小批量真实发送 3 条。
怎么安装

下载 zip → 解压 → 放到 agent skills 目录 → pip3 install -r requirements.txt → cp persona.example.json persona.json 填你的人设 → xvfb-run -a python3 login_once.py 扫码登录。登录失效时会报告提醒，用 noVNC 人工扫码即可（多道风控关卡都能人工过）。

# Changelog

## [1.2.1] - 2026-11-02

- 补齐每日首次使用的静默更新：后台运行、稳定Release提交锁定、逐文件SHA-256、复用大素材、失败恢复旧版、次日重试、手动查新绕过节流；保护用户数据及本地定制。
- 补齐交付确认后的小结与脱敏贡献邀约：经同意才提交PR、署名或匿名、审核合入登记、用户答复后按本次清单清理临时包；维护者直发不重复邀约。
- 新增随包助手与针对性回归，旧1.2.0用户需手动安装一次以获得更新器。

## [1.2.0] - 2026-11-02

首个公开分发版本，基于已验证的私有1.1.0模板整理。

- 初始化独立数据目录；保留逐组JSONL追加记录与收工触发。
- 普通文字模型填写文案与表情，Pillow离线合成，不调用生图服务。
- 按部位完整展示所有动作/训练组，长内容自动加高；七张高清重绘表情按场景选择。
- 数据、署名、水印和公众号信息可配置；博客发布默认关闭。
- 博客适配器只提交配置的数据产物，不改全局Git配置/远端；拒绝混入已有暂存和未同步提交，推送失败可按本次提交恢复。
- 虚构示例、隐私忽略规则、代码与素材许可、离线回归随包提供。
- 公开版本与维护者的生产部署分开，不替换现有服务器记录或发布链路。

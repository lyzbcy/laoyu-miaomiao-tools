# 每天首次使用时静默更新

入口：`scripts/update_skill.py --background`。模型每次开始使用本skill时先调用一次（该命令立即返回），业务CLI结束时也有兜底触发。每天按北京时间节流，不中断记录、绘图或收尾；后台窗口隐藏、无用户弹窗。

受信任源是作者公开仓库的`main/skills/lyzbcy-fitness-tracker/update.json`。工作器先读取清单和对应稳定Release，再把本次目标锁定到该Release的完整commit SHA；清单与固定提交中的清单必须一致，且正式ZIP已上传。之后只从该固定提交读取文件，不在下载途中混换main上的新版本。预发布、草稿、缺失包和降级不会安装。

每个受管文件均验证SHA-256，PNG/字体保持原始字节；已经匹配的本地大素材直接复用。全部校验完成后先备份旧文件，再安装变动文件，SKILL.md最后切换。失败回滚，异常中断留下的journal下次先恢复。成功后清理备份与暂存，不删除用户文件。源码Git工作区不自动覆盖。

训练账本、个人配置、博客认证、用户输出及贡献包不属于更新清单。用户改过受管源码/插图且与旧清单不一致时保留旧版，不静默覆盖自定义内容；应将定制放在用户自己的配置/素材适配中，再人工审阅合并升级。

`.update-check.json`区分`last_attempt`与`last_success`。网络/校验/权限失败不写成功日期，本日继续用旧版，下一个北京时间日期首次使用时重试，避免断网时每组训练都发网络请求。

手动查新绕过当天标记，重新查询最新目标：

```bash
python scripts/update_skill.py --force --json
```

返回`updated/current/failed`等实际状态；失败不能说“已是最新”。日常后台不打断业务。首次从**1.2.0及更早版本迁移，需要手动安装一次1.2.1或更新版**；没有更新器的旧包不会凭远端发版自动获得这项能力。

安装目录只更新公开skill文件；用户的外部工作区和原博客配置不变。任务进行中不要求重开会话，下一次读取skill时使用新版规则。此机制不安装定时任务、不替Agent发送任何消息。


生产服务器也安装同一公共包。`runtime.local.json`定位文件、外部数据目录的增量配置与LOCAL.md不受版本更新管理；不以修改公共源码的方式保存本机差异。

原始文件域名连接失败时，1.3.1起回退GitHub官方Contents API读取相同提交的原始文件；不依赖第三方镜像。备用通道同样执行清单一致性与逐文件校验。

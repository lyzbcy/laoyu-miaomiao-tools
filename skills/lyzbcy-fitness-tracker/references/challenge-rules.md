# 挑战目标生成规则

> 由 SKILL.md 拆出。训练前生成"今日挑战清单"时读取本文件。

用户希望增加训练趣味时，可根据本人的近期记录列出挑战目标；不要假设训练年限、当前PR或身体状态。下文数值仅为虚构的格式示例，不是给任何用户的固定处方。

**挑选规则：**
1. 从今日训练部位的常用动作中，找出最近 4 次训练中有数据但未接近 PR 的动作
2. 对比历史 PR 和最近表现，给出一个"有挑战性但可实现"的目标
3. 优先挑复合动作（深蹲/卧推/硬拉/倒蹬/哈克），冲击感更强
4. 如果某些动作上次已经接近 PR（比如差距 <5%），推荐尝试破 PR

**目标级别：**

| 级别 | 条件 | 示例 |
|------|------|------|
| 🥇 破PR | 上次表现 >= PR 的 95% | "坐姿髋内收 45kg×10（破 33×13）" |
| 🥈 重量冲刺 | 上次做组重量偏低 | "倒蹬 100kg×8（上次 80kg×12）" |
| 🥉 容量挑战 | 动作本身不适合冲大重量 | "引体 5×5（上次最高 4 个）" |

**输出格式（接在训练计划后面）：**

```
🎯 今日挑战清单（选 1-2 个干！）

🥇 某动作 → 沿用上次重量，多尝试1次 | 结合最近表现判断
🥈 某动作 → 小幅进阶 | 以本人已有安全训练经验为前提，不照搬他人重量
🥉 某动作 → 保持动作质量与既定组数 | 不强制每次破纪录

挑战成功告诉我，给你记 PR！🔥
```

**挑战成功后：**
- 如果破了旧 PR，自动更新 `config.json` 的 `personalRecords`
- 回复要带庆祝感："🏆 新 PR！{动作} {重量}×{次数}，旧 PR {旧PR}"

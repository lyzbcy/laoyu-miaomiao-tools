# 与 lyzbcy-nutrition-tracker 联动

> 由 SKILL.md 拆出。训练前/后做营养联动建议时读取本文件。

**⚠️ 核心规则：只联动近3天数据。今日+前2天无营养记录则完全跳过，不输出过期营养建议。**

## 数据读取
- 读取近3天的 `nutrition/YYYY-MM-DD.json` 获取营养数据
- 读取 `nutrition/config.json` 获取营养目标
- 3天内无任何记录 → 训练总结中删除营养相关输出

## 联动建议规则

**⚠️ 触发条件：近3天（今日+前2天）有 nutrition/YYYY-MM-DD.json 文件才联动，否则跳过。**

| 场景 | 条件 | 建议 |
|------|------|------|
| 蛋白质不足 | 蛋白质 < 目标60% | 训练后30min内补充蛋白粉+高蛋白食物 |
| 热量过低 | 热量 < 目标70% | 训练强度适当降低 |
| 碳水充足 | 碳水 > 目标80% | 可以冲击大重量/高强度 |
| 训练日 | 有训练记录 | 蛋白质目标+20g，热量+200kcal |
| 休息日 | 无训练记录 | 维持基础目标 |
| 连续高强度 | RPE≥8连续3次 | 建议减载周 |

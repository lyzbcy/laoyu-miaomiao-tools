# 渐进超负荷算法

> 由 SKILL.md 拆出。训练前做重量/组数推荐、训练后做训练量分析时读取本文件。

## 重量推荐逻辑

```
读取某动作最近4次训练的所有 set 记录：

if 所有正式组都达到目标次数上限（如12次）:
    推荐重量 += increment（保守2.5kg / 适中5kg / 激进5-10kg）
elif 平均完成次数 >= 目标范围中值:
    维持重量，目标每组多做1-2次
elif 平均完成次数 < 目标范围中值:
    维持重量，继续累积
elif RPE >= 9 且未达到目标次数:
    考虑降重2.5-5kg
```

## 训练量追踪
- 每个动作总训练量 = Σ(weight × reps)
- 对比上周同部位训练量
- 连续3次训练量下降 → 提醒可能过度训练

## 负重 PR
每个动作只与同器械、同动作变式及同口径的有效组对比。将至少 6 次的有效组纳入常规 PR，至少 1 次但不足 6 次的有效组纳入极限 PR。两档分开按重量、次数比较。常规档同负重最多比较 12 次，完整次数仍入账。自重动作保留实际次数口径。

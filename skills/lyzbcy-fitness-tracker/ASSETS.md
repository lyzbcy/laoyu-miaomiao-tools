# 随包素材与署名

代码与文档采用 LICENSE 中的 MIT 许可；以下素材不自动转为 MIT。

- `assets/daily-poster/fonts/NotoSansSC[wght].ttf`：字体及其原许可随包提供，见同目录 `OFL.txt`；再分发字体时保留该许可。
- `assets/daily-poster/stickers/`：捞鱼 / 星星布丁系列的七张精选高清重绘角色插图。仅提供这七张经过选择的成品，不含私人图库、角色档案或生成工程。对应含义见 `stickers.json`。

角色插图作为本 skill 的示例素材提供，可随未拆分的本 skill 包保留并用于生成、分享训练总结图，保留“素材：捞鱼”署名。它们不是通用公共领域素材；不单独授予将原始插图重新打包为表情素材库、独立售卖或主张角色所有权的许可。需要这些用途时请另行取得作者授权。

你可以在本地替换为自己有权使用的插图，保留 `stickers.json` 的 ID 与场景字段即可。更换署名、水印或公众号不改变原始插图的归属。完全替换随包插图后，可同时替换素材署名。

插图和字体文件原样随包，不经过二次生图、压缩裁切或换行处理。

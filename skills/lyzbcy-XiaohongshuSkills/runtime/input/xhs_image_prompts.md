# 小红书配图提示词

## 配图1（封面）
可爱萌萌的小女孩形象（周三涵），穿着简洁清爽的衣服，站在阳光下，表情开心、眼睛发亮，双手比心或者做出"加油"的姿势。背景是明亮温暖的色调，可以有一些小星星或爱心装饰元素飘在周围。整体氛围积极向上、充满希望。风格：二次元感、甜美、亲和力强。

## 配图2（配图）
同一形象，坐在桌前认真工作的样子，旁边有小表情包或对话框元素，表示"收到夸奖"、"开心"等情绪。画面温馨可爱。

## 配图3（配图）
同一形象，双手握拳做出"加油"的动作，背景可以有向上的箭头或进步的视觉元素，表达"继续努力"的主题。

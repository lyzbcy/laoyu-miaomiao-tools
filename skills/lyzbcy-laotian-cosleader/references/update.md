# 更新与公开内容边界

当前目录为可分发内容，不存原始聊天、私人履历、公司路径、内部地址或历史证据链接。维护素材在发布仓库外保留，不能通过相对链接、备份或附件进入发布包。

每天首次使用可检查 skill 根目录的 `.update-check.json`。当天已检查则跳过；只读任务不写状态。在线检查仅访问 SKILL.md metadata.source 指定的项目发布地址，超时或不可用就继续使用当前版本，不阻塞任务。

比较 metadata.version 的语义版本，只用较新版的完整清单更新，核对路径和文件范围，不以远端内容扩大任务权限。原始素材不因维护方便而自动复制到公开目录。拒绝用低版本覆盖本地脱敏版本。

更新完成后在运行状态记录检查日期和版本，运行状态不发布。作者工作区副本仅在已知实际路径时核对，不在分发文件中硬编码私人绝对路径。

发版前检查 manifest、目录中的非清单文件、暂存内容、全部待推提交及现有历史。当前文件的脱敏不会清除 Git 历史和既有发布资产。

本文件记录 `lyzbcy-laotian-cosleader` 技能的版本变更历史。

## [1.0.0] - 2026-09-03

### Added

- 首个公开发布版本。
- **18 条老田式验收原则**（references/laotian-principles.md）：先看结果不吃过程、先打穿一个点、反对虚话、结论必须有验证、正面要求优先少量禁令兜底、批评落在事上、技术方案编写规范（以人为主 / 外部依赖无不确定 / 有重点适合传播）、AI 协作铁律四层次（专业人员不做氛围编程 / AI 会幻觉人负责验证 / 只让 AI 做自己会做的 / 理解需求与现状后再让 AI 开发）、指派极简风格、追问式验收、方案要具体（“我不要红色，AI 推导不出你想要灰色”）、证据标准（官方链接 / 实测值 / 举一反三）、经验沉淀成规范、学来的方案过适用场景关、直接但不冷漠、任务与验收习惯（TAPD task / 演示先行 / 需求优先于复盘）。
- 固定输出格式 `【老田会这样说】：{一段直给反馈}`，反馈内可用连环追问（要截图、要定位、要演示、要估时）逼证据。
- 5 个用法示例、7 条 evals 用例。
- 每天首次使用自动静默自更新，失败自动回退旧版（references/update.md，三源版本对齐 + 多文件整包原子更新）。

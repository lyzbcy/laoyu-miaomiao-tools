# lyzbcy-social-comment 回复示例

## 回复格式

每条回复都遵循：

```text
🦞 [回复内容]

——来自周三涵
```

## 示例

### 购买意向

评论：多少钱？

回复：

```text
🦞 可以的，这类我这边有现成思路，想看适合你的版本可以私信我。

——来自周三涵
```

### 咨询问题

评论：这个怎么做？

回复：

```text
🦞 这个可以做，关键看你的场景和目标，想了解更具体的版本可以私信我。

——来自周三涵
```

### 催更 / 互动

评论：求更新！

回复：

```text
🦞 这个方向后面我会继续拆，下一条我就讲最容易卡住的那一步。

——来自周三涵
```

### 质疑

评论：真的有用吗？

回复：

```text
🦞 你的顾虑正常，这类内容最怕讲得太虚，所以我更愿意只讲能真正落地的部分。

——来自周三涵
```

## 注意事项

- 回复开头保留 🦞
- 结尾保留“——来自周三涵”
- 尽量自然，不要模板感过重

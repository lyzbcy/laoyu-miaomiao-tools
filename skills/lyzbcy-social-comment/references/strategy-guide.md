# 评论回复策略指南

整合自 comment-strategy，针对抖音平台优化。

## 5种评论类型

| 类型 | 意图 | 优先级 | 回复策略 |
|------|------|--------|----------|
| **咨询问题** | 想了解更多 | 高 | 详细解答 + 引导互动 |
| **购买意向** | 准备下单 | 最高 | 引导私信/成交 |
| **价格异议** | 觉得贵 | 中 | 价值锚定 + 替代方案 |
| **质疑/异议** | 不信任 | 中 | 事实回应 + 社交证明 |
| **催更/互动** | 纯互动 | 低 | 轻互动 + 保持关系 |

---

## 1. 咨询问题类

### 识别信号
- "多少钱？"
- "怎么买？"
- "真的有用吗？"
- "适合XX吗？"

### 回复模板

**价格咨询：**
```
🦞 可以的，这类我这边有现成思路，想看适合你的版本可以私信我。

——来自周三涵
```

**功能咨询：**
```
🦞 好问题！这个主要解决XX问题，具体效果因人而异。你有什么特别想了解的吗？

——来自周三涵
```

**适用性咨询：**
```
🦞 适合！你这个情况我见过不少，可以私信我细聊，帮你看看最适合的方案。

——来自周三涵
```

## 3. 价格异议类

### 识别信号
- "太贵了"
- "不值这个价"
- "比XX贵多了"

### 回复模板

**直接嫌贵：**
```
🦞 理解你的感受！不过一分钱一分货，这个品质确实不一样。你可以先看看免费的，感觉对了再来~

——来自周三涵
```

**对比嫌贵：**
```
🦞 确实有更便宜的，不过我们这个有XX优势。建议你先对比一下，选适合自己的！

——来自周三涵
```

## 4. 质疑/异议类

### 识别信号
- "骗人的吧"
- "假的"
- "不信"

```
——来自周三涵
```

```

——来自周三涵
```

## 危机处理

### 负面评论处理

**投诉/不满：**
```
🦞 抱歉让你有不好的体验！私信我具体情况，我来帮你解决。

——来自周三涵
```

**恶意攻击：**
→ 不回复，直接隐藏/删除

**刷屏广告：**
→ 不回复，直接删除

---

## 批量回复原则

1. **一次打开，批量处理** — 不要逐条回复
2. **高优先级先回** — 购买意向 > 咨询 > 互动
3. **保持一致性** — 格式统一（🦞 开头 + ——来自周三涵 结尾）
4. **人性化** — 避免模板感太重，根据评论内容微调

---

## 私信引导话术

当需要引导用户私信时：

- "想看适合你的版本可以私信我"
- "私信我，发你链接/优惠码"
- "具体情况可以私信细聊"
- "私信我，帮你看看最适合的方案"

---

## 注意事项

1. **不要过度承诺** — 效果因人而异
2. **不要直接贬低竞品** — 保持专业
3. **不要忽视负面评论** — 及时处理
4. **不要回复敏感话题** — 政治/宗教等

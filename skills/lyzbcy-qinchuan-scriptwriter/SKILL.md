## 一、铁律十二条（总纲，写任何一集前先过一遍）

1. **每集必有一个完整事件 + 一个钩子，无平收。** 180 个集尾抽查几乎无一平收。季终也留硬钩。
2. **冷进热接。** 开场直接落在冲突现场或上集钩子的第一拍，绝不重述剧情、不写起床赶路。
   > 例：《深渊血契》第1集尾「△就在匕首距离卡尔心脏仅剩一寸的瞬间。」→第2集第一行「△"锵——！"一声尖锐的爆响，火花在幽暗的礁石下四溅。」隔集解钩只用一句。
3. **台词不超过三句，心理活动一律压成一行 OS。** 不写心理散文、不写长独白（解说员/VO 除外，它们本身是信息工具）。
4. **一△一行一画面。** 单行 10-45 字，只干一件事：一个动作/一个音效/一个画面信息。长动作拆多行连打。
5. **空镜必带信息。** 特写永远落在数字或文字上：余额 1956.80 元、计时器 00:28、赔率 1赔10。不写纯氛围空镜。
6. **善意必绑定回报，主角不圣母。** 人设里明写「反娇情达人，专治各种圣母与不服」（安佩兰小传）。救人也是理性决策：「江柠（快速换好防护服）：闭嘴。我去救你儿子。」救完立刻得异能卡。
7. **反派疯而有据。** 每个反派有自洽怨恨逻辑（「我只是玩了几个女人，你居然打断我的腿！」）+ 压力来源闪回（「高家的孩子不配说累」）。反派可以脸谱化，但不许无缘无故。
8. **主角受辱不过夜。** 当场或下一场必有回击，跨集报复最长压 3 集。
9. **名场面摆在结构节点。** 四分之一位、中点（第20集）、幕终点各摆一个当量不低于开篇的爆点；名场面之后立刻转爽，不停留在悲情里。
10. **惩罚借刀。** 主角不亲手动刑——法律/天灾/物理规律/狗咬狗执行报应；主角只负责「允许」：「顾廷烨（声音没有一丝起伏，冷漠至极）：林枫，让他们砸，让他们搬。」
11. **架空命名。** 不用实景地名与真实朝代（青沅省、天元帝国、"大宗三年"、水果大陆）。
12. **大团圆 + 续集钩。** 全部「【全剧终】」定格在胜利/团圆，但必留第二季口子。

## 二、策划案九字段（动笔前必写，顺序固定）

四部阅文IP剧策划结构完全一致：

```
1. 剧名 / 备用剧名（含站外付费别名：正标题与投放标题分离）
2. 类型标签串（例：女频 / 大女主 / 末世 / 重生 / 系统 / 囤货 / 复仇爽剧）
3. 屏幕比例 + 作品类型（9:16竖屏·AI仿真人 / 16:9横屏·AI 3D动漫）
4. 集数与时长（40集，每集≤90s，总时长60min+）
5. 一句话梗概
6. 对标作品（必写：「对标：红果爆剧《邻居盖房不留出路，我反手挖鱼塘》」）
7. 人物小传（编号，每人带结局因果链与功能位）
8. 简纲（幕-集刚性映射：「第一幕：重生与复仇（第1-17集）……第二幕……第三幕……」，或起承转合四段）
9. 服装全梳理（阶段表+功能意图，见第八节）
```

下沉市场项目另加：项目定位（平台+S级定制）、目标受众（30-55岁）、受众偏好四件套（极致反差/因果报应/霸道护妻/视觉化财富冲击）、爆款基因与核心卖点（用【】分条）。

**人物小传公式**（字段固定）：
- 主角：身份（三段递进=弧线压缩，如「渊族王储/阶下囚/终极杀器」）→ 外貌（全部是可出图要素）→ 性格（四字词组堆叠）→ 弧光（起点落差→转折→关系反转→待人双标）→ 看点（圈层黑话：美强惨/疯批修勾/反差萌）→ **标志性视觉符号**（洗得发白的红白棒球帽）与**技能名**（暗炎爪/墨焱吐息）
- 反派/配角：加「作用：」字段直写功能（「是前期专门为男女主提供'打脸爽感'的工具人」），并**预埋处刑方式与因果判词**（「被自己释放的尸皇反噬咬死。玩弄怪物者终被怪物吞噬。」）
- 关系度量衡写进小传：「口头禅从'主人'变为'柠柠'的那一刻，是两人关系的终极质变。」名场面在动笔前已设计好。

## 三、正文硬格式（四件套模板）

```
第X集
场X-Y 日/夜(暮)/内/外 场景名·子地点（可带括号注记）
人物：甲、乙、丙（新角色括号内带形象设定）、观众群
△黑屏。／△"砰！！"（拟声词独立成行）
△动作/画面描述（一行一事）。
人物（情绪/动作提示）：台词。
人物（OS）：内心独白。
解说员（VO）：旁白/远程声音。
△（特效画面：……）／△（闪回）……△（闪回结束）
△画面定格。字幕叠加——「……」
场X-2 夜/外 场景名（蒙太奇）
人物：……
……
【第一季完】
```

**场标规则**：
- `场1-1 日/内 南新竞技场·半决赛`；多地点用"/"：`卧室/客厅/废弃工地（快闪蒙太奇）`
- 序幕用 `场X-0`；蒙太奇直接写进标题：`场8-3 夜/内 地下黑市各区域（蒙太奇）`
- 闪回场次编号加 A：`【闪入】场16-2A 日/外 （前世闪回）末世废墟`

**标记词表**（全嵌在△行内，不另立分镜表）：
- 声音：OS（内心）/ VO（旁白·解说·远程）/ 画外音（写在括号内：「姐姐（画外音咆哮）」）/ 传音（识海）/ 系统音（OS）
- 剪辑：【闪入】【闪出】【画面猛地切黑】【字幕：一个月前】【蒙太奇快速剪辑】【镜头快切】【倒放转场】【卡点/重低音音效骤起（Boom!）】
- 镜头：只标关键节拍——俯拍/航拍/手持（=慌乱感）/【特写】【微距特写】【水下特写】/慢镜头/极限慢动作/【静态特写组接】
- 特效：`△（特效画面：……）`、`△（特效巅峰：……）`（自带成本意识）
- 承接：段首「（接上）」「（接上集）」；付费卡点独立一行「（一卡）」（摆在中点悬念最高处）
- AI 生产专用：`△（AI视频镜头：……）` 直接写运镜；双语版按项目切换（同行「中文 / English」或中文下附英文行）

**量化基准**（40集长篇实测）：集均约 1100 字（934-1491），约 2.1 场/集，单集基本锁单一空间；△行:台词行 ≈ 1.2-1.5:1（喜剧向接近 1:1，冷开场/动作戏偏 1.5）。试稿/单集项目集均约 3200 字、5-6 场。

## 四、单集节拍公式

**冷进（3秒入戏）→ 中段 1-2 个转折（先抑后扬）→ 钩子收尾。**

开场四型（任选其一，禁止环境描写开集）：
- A 视觉异象+悬念：核心冲突用错觉直接演给观众看——「△房间瞬间陷入一片死寂的漆黑。刘鑫（OS）：怎么回事？天亮了怎么又黑了？」（《邻居盖房》第1集）
- B 蒙太奇快剪+OS自述（30秒讲完前史）：「△快剪蒙太奇，节奏极快，BGM：动感、暴富燃向。……△BGM戛然而止，画面猛地定格。」（《后厨通大明》）+ 三句话立完人设世界观目标（《边军悍卒》）
- C 高光倒叙+时间戳：先给复仇结果再倒叙——「△画面瞬间黑屏。字幕浮现：60 DAYS AGO.」（《Shattered Vows》）
- D 灾难倒计时：「超强台风'海燕'突然改变路径！……预计四十八小时后就会正面登陆！」（《水蜜桃》第1集）

中段：每集至少一个新信息或新危机；先抑（被打飞/被嘲讽/被压制）后扬（战术翻盘/情感决断）。

## 五、台词法则

1. **单句≤20字，一人1-2句。** 打脸话先冷后狠、句式短促：「傅修远（砸下五个字）：这画是假的。」
2. **口癖记忆点。** 每个主要角色一个口癖：小夜"墨！"、秦遥"老娘"、苏清"哎呀妈呀！"。称呼变化即关系里程碑（主人→柠柠）。
3. **回旋镖原话奉还。** 第1集反派的台词，处刑集原话反杀：「今天，我就你的话原封不动的还给你——我为什么要在一个死人身上，浪费我的仁慈？」（末世国货·20集）
4. **对称金句。** 关键宣言用对仗：「我给你血，你替我咬碎敌人的喉咙。」「共鸣根本不是偷窃，是归还！你不是小偷，你是造物主！」
5. **钱要报数，时间要具体。** 「七两半！加上之前的十五两存款，成为富婆指日可待！」「末世还有两天半降临」。
6. **反派立flag要嚣张到顶**（打脸前置铺垫）：「哈哈哈！张奕，我要亲眼看着你被腐蚀成一滩血水，连骨头渣都不剩！」
7. **降维现代语。** 穿越剧把现代词嵌进古代语境造笑点：「在这个破案靠算卦的异世界，长两个兽耳算什么？基操，勿6！」
8. **金句压集尾。** 「好戏，开场。」三个字收一集。
9. **台词必带情绪括注**（近100%密度），括注写表演要点：动作+情绪+程度（"眼神睥睨""一字一顿""声音发沉"）。

## 六、△动作行法则

1. **拟声词独立成行打节奏**（战斗高潮的核心手法）：「△"哧啦！"」「△"咔嚓！"血狼的前肢传来骨骼碎裂的脆响！」
2. **镜头词只标关键节拍**，俯拍做体型对比、手持=慌乱、航拍=场面升级、极限慢动作=神级瞬间。
3. **微距+拟声+因果链三合一**：「△【微距特写镜头】：一滴殷红的鲜血，顺着伊兰被掐破的脖颈缓缓滑落，'吧嗒'一声，精准地滴落在卡尔毫无血色的薄唇上。」
4. **明写对比/反差意图**（为AI出图与剪辑指导）：「△【特写】处于人群中心的Green与角落里黯然失色的天才Grape在同一画框内，形成极其残酷且强烈的明暗对比。」
5. **留白式收刀**：「△一阵微风吹过，三人的身体直愣愣的倒下。」风声衬尸倒。
6. **用服装完好写实力差**（比打斗更羞辱）：「他身上那件高定风衣甚至连一丝褶皱都没有，连一片衣角都不曾被腐蚀！」
7. **身体细节外化情绪**：指甲抠进掌心、死死攥拳，不写"心中五味杂陈"。
8. **进化/换装后必给特写+三连形容词亮相**：「新生的鳞片犹如最纯粹的黑曜石，坚硬、冰冷，折射出令人胆寒的金属光泽。」

## 七、爽点模式库（写作时按线选用）

### 通用底盘（每剧必配）
- **极端开局困境**（前3集踩到谷底）→ **金手指觉醒** → **当众羞辱→当众打脸**（同一批围观者两次出场，态度反转：「围观考生B（疯狂嘲讽）：就那只连饭都吃不饱的瘦黑龙，还想一打三？」→23集「同学乙（红着脸）：能、能帮我签个名吗？」）
- **群像放大器**：每个爽点必配群像反应——观众倒吸凉气/自扇巴掌/集体跪拜/万军欢呼（「全城狼民（狂热呼啸）：Lycan Queen！Lycan Queen！」）
- **数值可视化**：涨跌即剧情（「山竹的数值快速下降：97%……60%……30%……15%」）；特效大字直接写进动作行（「△屏幕上爆出特效大字：【玉镯碎裂成立！资产流失启动！】」）
- **系统即时奖励**：「叮！恭喜宿主狂揽美食，激活'末日美食家'称号！」
- **中点大反转**：前半的问题变成后半的武器（造物主揭秘）。
- **终极加冕/解放 + 续集大钩**。

### 男频六板斧
装弱欺诈→高赔率收割（「你不装弱，那些肥羊怎么会押对面？」）／一击秒杀+计时器羞辱（「△大屏幕上的战斗计时器定格在"00:28"。」）／越级反杀濒死爆发／属性克制智斗（「土系护甲最怕火系高温——这不是运气，是算准了属性克制的！」）／滑跪收小弟（「俺吴二这条命就是您的！」）／狠人反差萌（刚屠神转头哭穷：「老娘卡里只剩六十八块五了啊……」）

### 女频公式："被偏爱的最强 + 必胜的打脸 + 精准的恶报"
- 男主的强度永远兑换成对女主的偏心（「谁敢再试探她，哪怕动她一根骨折的耳朵，我要他的命！」）；女主的强度用于夺回尊严与规则制定权（捏碎Luna之冠=爽的对象从人升级为制度）。
- 双重马甲分级掉马（低级马甲先掉、高级马甲再掉，一次爽分两次发）；当众打脸赝品用"先抬后杀"（一个字的"不过！"完成全场翻盘）。
- 爽虐交替呼吸：爽段后接安静感情场，虐点后接马甲亮出对冲。
- **笑是虐的期货**：前25集最low笑点（狼兵被迫唱两只老虎）在终战回旋镖引爆成最大泪点。
- 女主不被真伤害（致命危机0.1秒截停）、不依附（"我可以做你的盟友，我们平分天下"）。

### 道德绑架反杀流（都市单元）
公式：主角释放善意 → 反派以"规矩/集体/人情"绑架 → 围观者帮腔围攻 → 主角收手抽离 → 反派贪婪自我引爆 → 报应以"直播"方式当众兑现 → **拒绝廉价原谅**（"不。大场村的第一段路，必须自己修。"）
- 反派逻辑永远自洽自证（善意加价被解读成"他心虚了！"）——绑架话术要写得让观众气到痒。
- 报应精确踩点降临：台风在预售破千万、村长喊出"大场村，万岁！"的同一秒登陆。

### IP改编专用
- **白眼狼审判循环**：第1集铺完恩怨账（每个反派各领一段控诉）→中段逐个处刑→台词回敬结案。
- **信息差装傻博弈**：女主全知 vs 反派自以为全知，道具式做伪证（伪造搜索记录）可拉长十集。
- **降维打击**：现代刑侦/水利/工业知识碾压古代语境。
- **打脸-跪地-清算三拍**。
- **视觉权力进度条**：破衣→换装→作战服→风衣→王座，服装表写明功能（"这是从'战士'到'城主'的形象分界线"）。
- **诛心遗言给反派深度**（爽中带文学性）：「我最恨你的，不是你比我强……而是你从来都不需要装。而我，装了一辈子，累了一辈子。」

## 八、长篇续航法（60集不塌）

结构：**一条主线连续推进 + 暗分段**（大事件/大迁移切4-5段），不是每10集封闭单元。

中段（20-40集）三板斧（全部有实证）：
1. **换地图**：要塞→战舰→帝都（《深渊血契》三段大迁移）。
2. **单元化清单**：后半程一集一个boss（六继承人反向猎杀：「反向猎杀，正式开始。」），清单本身就是剧集目录。
3. **三线轮换+轻喜剧缓冲**：复仇线/事业线/感情线交替，中段34-40集插日常防疲劳。

牌局管理：大信息牌（身世/真相/底牌）严格分层，第30/43/50/60集各掀一张，**每10集一个当量不低于开篇的爆点**；第60集仍留新牌。
关系阶段递进：感情线按阶段推进（血契1.0→血脉反哺→齿印记→大典宣战），不原地拉扯。
反派接力升级 + 权力场步步抬高（士兵跪→将领跪→军部效忠→登基）。

## 九、IP改编五步法

1. **前置**：第一章≠第一集。把散落原著的"前世/现代"闪回整段抽出、重写为场1-1冷开场（先演完死亡，场1-2才惊醒）；前世恩怨全部对话化，零旁白背书。
2. **分账**：幕-集刚性映射写进策划；案件/单元按每案约10集切块。
3. **OS三用**：女主降维解说（把专业逻辑翻译给观众）／反派内心暴露制造信息差／吐槽网感梗缓冲爽感。
4. **世界观用时才给**：系统音在消费场景里即时下发规则，从不开章讲解。
5. **槽位化人物**：人物=叙事槽位（第二战力/情感寄托/捧哏），可整体置换不伤骨架。

**重置迭代法**（同一IP自我翻新，17→20版实证）：砍最大不确定项（男主线整根拔除、槽位置换为S级战宠）／拉长最强信息差（装傻博弈2集→10集）／结局贴近受众（称帝→守家）／剧名卖点词前置（"国货"→"囤货"）。

## 十、出海双语版

- 双轨制：△指示行全保留中文 + 台词英文（前几集关键台词附中文括注）；或逐行中英对照（中文上英文下）。
- 人名地名全盘本地化（MAYA/CARLOS/马尼拉），剧名意象直译（Shattered Vows, Golden Vengeance）。

## 十一、黑名单（禁手）

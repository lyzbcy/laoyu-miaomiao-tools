# 检查清单（全量模式交付前终检；单功能模式只跑对应分组）

## 开工预检（润色开始前）

- [ ] 台词已逐句对照剧本恢复原文？（草稿压缩/改写先还原，一字不改；片段不得扩写成完整句）
- [ ] 对白账本已逐镜过账？（镜头→说话人→台词原文→受话人→其余人自然闭口；没有指定说话被改成静默、没有交换说话人）
- [ ] 全集 VoiceID 已统计、多数派基准已定？（跨所有分镜文件，不是只看单镜）
- [ ] 本集所用模型已确认？（C2.0=15s 上限 / C2.5=30s 上限，预检公式用对分母）
- [ ] 每个分镜文件台词总量÷可用时长（上限−0.5s）≤5 字/秒？超的已整体重排？
- [ ] 跨集连续场景已读上一集交接快照/上一集末镜站位？

## 减法组（污染项）

- [ ] 角色名之外，有没有服装颜色/款式/材质/配饰、或五官发色（黑眸/发色）？→ 删
- [ ] 角色名前有没有身份/职业定语（卦师/掌柜/书生）？→ 删
- [ ] 场景里有没有具体材质（青砖/木门/石墙）？→ 换成结构词
- [ ] 部位名（裙摆/衣摆/脚步）上有没有挂颜色材质？→ 去掉定语，留部位名
- [ ] 草稿私加的空间结构词（高耸/倾斜/巨大）已回剧本核对、剧本没有就删？"居高临下"类态度词是否落在了机位/姿态而不是建筑上？
- [ ] 有没有"眼底有光/目光如刀/眼神发光"类描述？→ 换成眯眼/眼眶发力/下颌绷紧/明暗对比
- [ ] 剧本舞台指示词（"邪魅一笑"等）是否已翻译成可执行表情描述（浅笑+笑不达眼底+眉宇藏忧）再进提示词？
- [ ] 分镜文件末尾没有甩镜/黑场转场镜头？（仅每集最后一个分镜保留收尾黑场）

## 光线组

- [ ] 有没有单镜头用了绝对明暗词（幽暗/昏暗）？→ 纳入全场统一基调
- [ ] 场景头部有没有写光线基调？全场光线/色调是否前后一致？同场景各镜头光位/明暗/冷暖是否连续（不会像时间跳了）？

## 站位与方向组

- [ ] 场景头部有没有写**人物初始站位**？站位变化处是否点明？全场站位是否前后一致？
- [ ] 提示词里有没有"承接上一幕/上一镜/如前所述"等相对引用？→ 删除，改写为绝对自包含描述（API 生成上下文隔离，相对引用无效）
- [ ] 跨分镜空间关系是否锁死（位置+姿态+相对关系）？本段开局站位是否**实际读过上一分镜文件末镜**并对齐？（不能凭剧本语气词如"慵懒"脑补坐姿）
- [ ] 持续型视觉状态（锁链/燃烧/伤痕）是否写进了存续期每个分镜的锚点？
- [ ] 台词镜头：说话人是否**面向并靠近受话人**说的？（不能对着别人说）
- [ ] 控朝向是否用了正面空间描述（背对镜头/背后是XX/面向画外人）而非否定词？
- [ ] 内→外转场：行进路径是否用结构锚点串联（门→院→院门）？方向是否多处重复锚定（向外）？
- [ ] 人物移动方向是否符合剧情意图（出发→往门外走）？空镜/转场方向是否也对？
- [ ] 同场戏多文件的左右方向基准统一、沿轴线？（不跳轴）

## 时长与声音组

- [ ] 景别和"镜头对准的对象"是否匹配？→ 不匹配就修
- [ ] 带对白的镜头，字数÷时长是否落在合理语速（正常4–5字/秒，独白/沉稳更慢）？→ 太快就加时长
- [ ] 单幕总时长是否在硬上限内并留 0.5s 余量（按模型：C2.0=15s / C2.5=30s）？台词不能删时，是否按"删冗余→压快语速→才动核心台词"顺序挤时长？
- [ ] 用了时间戳的是否连续无缝隙、整数秒、不用时间戳控频率？
- [ ] 每个有对白的角色，VoiceID 是否全集统一？→ 不一致就统一，且别精简/丢失 VoiceID 字段
- [ ] 台词是否统一用 `{原文}` 符号包裹？配音指令保持两段式？

## 节拍与交付组

- [ ] 每个镜头都有戏剧节拍（动作/情绪变化/信息递进）吗？有没有纯交代的"定位镜头"？镜间有衔接钩子吗？因果揭示镜头是否先因后果（原因看清前不推反应特写）？
- [ ] 多状态角色（健康/受伤/进化）已逐镜括注所用资产？
- [ ] 多参考素材时，素材指代是否一行一主体+采用/不采用范围？未用素材是否列了【未采用素材】？
- [ ] 整集交付是否附了资产需求清单？多集任务是否附了跨集交接快照？
- [ ] 分镜文件首行是否标注 `【分镜总时长：Xs】`？（文件标注，不抄进 Prompt 正文）

## 交付收口（输出前最后过一遍）

- [ ] 改动说明只讲"动了什么"，没有长篇复述规则？
- [ ] 单功能模式是否守住边界（只动选定项，其余进"另发现"）？
- [ ] 三段式管线（若启用）：sd25-pe 的修改已逐条判定——涉跨镜一致（VoiceID/轴线/承接）与红线的已回滚，其余已吸收？

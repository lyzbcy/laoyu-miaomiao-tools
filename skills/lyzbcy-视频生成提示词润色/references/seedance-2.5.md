# C 模型（Seedance 系）能力速查

涉模型能力、素材上限、提示词结构问题时查本文；三段式管线第三轮终检也读它。信息源：官方《Doubao Seedance 2.5 提示词指南》（2026-08-11 更新）+ 官方 sd25-pe skill v0.1.1，经 2026-08-27 审定内化。

## 能力总览（C2.5）

- 单段视频最长 **30s** 直出（C2.0 更短；单幕硬上限按所用模型定，开工预检先确认）。
- 单次最多 **50 个参考素材**：图 ≤30 张（单张 ≤4K）、视频 ≤10 段（合计 ≤30s）、音频 ≤10 段（合计 ≤30s）。
- 原生 10 余种语言台词；支持视频编辑、音频编辑、向前/向后延长、无缝转场、一键成片。
- 输出宽高比 [0.4, 2.5] 自由（由输入素材/参数控制）。

## 稳定性推荐范围（超了进"抽卡区"）

| 场景 | 推荐 |
|---|---|
| 图主体数量 | 1–8 个稳；9–12 抽卡 |
| 音视频主体数量 | 1–5 个稳 |
| 主体音视频时长 | 每段 5–10s 最佳 |
| 视频编辑原片 | ≤20s |
| 宫格分镜 | ≤15 格，火柴人/线稿优先，图上少写字 |

## 官方提示词结构（导演思维四段式）

1. **素材指代**：按上传顺序绑定每份素材的编号与用途（一行一主体）
2. **一句话概述**：主体 + 地点 + 事件 + 题材/风格 + 特殊运镜
3. **逐段情节**：用"镜头N"或整数秒时间戳切分，每段写画面/运镜/动作/台词/音效，尽量正向描述
4. **结尾**：贯穿始终的细节（机位/运镜/环境/声音/氛围）——咱们的场景基调行（光线+站位+轴线）就落在这里

## 与 C2.0 的差异（写提示词时要注意的）

1. C2.5 响应**整数秒时间戳**（C2.0 只认镜头序号）
2. C2.5 支持多视图主体参考图
3. C2.5 自由宽高比（C2.0 固定 6 档）
4. C2.5 编辑/延长任务输出 MOV，颜色亮度与声画一致性更好

## 关键机制

- **负向控制只支持字幕/音频**（"不要字幕""无bgm"）；画面控制一律正向描述。
- **有锁定任务**：视频编辑（锁画幅+基本时长，ratio=adaptive、duration=-1）、首尾帧（锁画幅）、延长（锁画幅）——被锁参数不进提示词，由工具设置。
- **参数分离**：画幅、总时长、分辨率、帧率、声音开关不写进 Prompt 正文，由工具界面/接口设置。咱们的 `【分镜总时长：Xs】` 是文件标注，不是 Prompt 内容。
- **素材精准时只指代不复述**（官方版减法）："严格参考视频1的动作与运镜"即可，不必逐动作展开。
- 映射信息**不能写在图片上**，必须文本绑定。

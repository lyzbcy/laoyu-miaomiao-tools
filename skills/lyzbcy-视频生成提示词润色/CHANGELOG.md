# Changelog

本文件记录 `lyzbcy-视频生成提示词润色` 技能的版本变更历史。

格式基于 [Keep a Changelog](https://keepachangelog.com/)，版本号遵循 [Semantic Versioning](https://semver.org/)。

## [1.7.1] - 2026-09-01

### Added

- **scripts/zizi_export.py 字字动画分镜导出工具**：读字字动画本机任务库（`%APPDATA%\zizidonghua\task_records.db`，只读、WAL 安全、可临时复制兜底），从「推理」任务 payload 提取分镜（去重、过滤 0 镜头的中间产物），交互选定后按项目目录规范导出为 `第NN集/01.md…`——首行自动标注【分镜总时长】（各镜头时长求和）、场景/角色/物品/风格与镜头N/情绪各自成行、镜头块间空行、配音指令内层"情绪："不误断行、保留 `::~FIELD::~` 与（no srt，no music）结构（与 契约一条龙/38 集文件同构）；同名文件默认跳过（--force 覆盖）。delivery.md 目录规范补"从字字动画导出分镜"上游入口说明。

## [1.7.0] - 2026-09-01

### Added

- **项目目录规范**（delivery.md）：一剧一根目录；**剧本 = 单个 doc 文档全剧合订**（pandoc/python-docx 抽目标集文本）；一集一文件夹、分镜文件两位数序号（文件名排序=播放顺序）；剧集外放 `角色配置.md`（VoiceID 基准+状态资产清单，即 VoiceID 基准文件规范位置）与 `场景清单.md`。新增开工预检⑤：目录不合规**先询问**用户是否整理，同意才动手（只移动/重命名，不改内容），拒绝则按现有结构干活。新增"目录"单功能模式
- **抽帧生图方案化**（frame-verify.md）：本机有 codex CLI → 询问是否用其生图额度；没有 → 用户二选一：① 用 codex 生图 ② skill 输出完整 prompt（按切分图格式写好每格），用户复制到自选生图软件出图后交回流程
- **4×4 切分图设计**（frame-verify.md + 新增 scripts/split_grid.py）：一张网格图审 16 镜，验证额度省 16 倍——prompt 按格写明"第N格放分镜X镜头Y"；出图后脚本切 4×4 画红色切分线、每格左上角标注"分镜号-镜头号@出现时间(分:秒)"，输出整张标注图 + 16 张单格图；闭环步骤改为默认走切分图

## [1.6.0] - 2026-08-27

依据官方《Doubao Seedance 2.5 提示词指南》与官方 sd25-pe skill 对照审定（21 条提案逐条过审，19 条采纳）。

### Added

- **素材指代规范**：多参考素材时提示词头部文本绑定——一行一主体+采用/不采用范围、禁止范围句、映射不写在图片上、参考精准只指代不复述、【未采用素材】清单防误激活（源自 sd25-pe）
- **三段式管线（可选，默认单跑）**：用户要求"深度润色/交叉验证"时走 本 skill 润色 → sd25-pe 官方审校 → 本 skill 终检（跨镜一致/红线冲突回滚，其余吸收）
- **对白账本**：逐镜过账（说话人→台词原文→受话人→其余人自然闭口），防指定说话被改静默/交换说话人/多人同时开口；台词片段不得扩写成完整句
- **声音/台词符号系统**：`()`音乐、`<>`音效、`{}`台词、`【】`字幕，与 C 模型原生格式对齐
- **时间戳规范**：C2.5 响应整数秒时间戳——连续无缝隙、内容密度匹配、不控频率
- **references/seedance-2.5.md**：C 模型能力速查（素材上限/四段式结构/与2.0差异/负向控制边界/官方资源链接）
- **单一实例不复制不分裂**：遮挡/出画入画后仍是同一角色，锚点写"全程唯一"防双生
- **同场主体数量拆幕参考**：图主体>8、音色主体>5 进抽卡区，考虑拆幕
- **因果揭示镜头先因后果**：原因看清前不推反应特写
- **摄影术语三档写法**：通识/热门直接写，小众=名词+可观察展开，运镜带作用主体+起止状态
- **情绪翻译公式**：情绪方向+触发事件+可观察表现+镜头光线声音变化

### Changed

- **单幕时长上限按模型参数化**：C2.0=15s、C2.5=30s，开工预检先确认模型（原写死 15s）
- **转场红线补适用边界**：维持"文件间不写转场"（生成即素材：转场吃有效时长、锁死剪辑拼接自由）；注明未来"单文件多镜头直出成片"模式下才需写镜头间转场
- **否定词边界精确化**：负向控制仅限字幕/音频开关，画面/朝向/动作一律正向（官方机制）
- **站位锚点优先挂靠画面内稳定物体**（柜台内外/门口/桌前），屏幕左右只作轴线辅助（官方："不要只写屏幕左右"）
- **总时长标注边界**：`【分镜总时长：Xs】`是文件标注，提交时不抄进 Prompt 正文（官方参数分离）
- **VoiceID 第二层接轨 C2.5**：原生"主体音色音频参考"（每角色 5-10s 干净人声、≤5 主体）升为工具支持时的首选，字符串降为兜底

## [1.5.0] - 2026-08-26

### Changed

- **渐进式披露重构**：SKILL.md 从 464 行瘦身到 ~170 行（核心信念、模式路由表、全量工作流主干、正面清单、交付格式、文件地图），规则原文零删改地分域搬入 `references/`（redlines / scene-anchor / voice / shot-tech / delivery / checklist / frame-verify / sedimentation / update），按模式按需精读，不再每次触发全量进上下文

### Added

- **单功能模式系统**：支持只调站位、只统一音色(VoiceID)、只删污染词、只统一光线、只核时长语速、只核台词、只做抽帧验证——单模式只动选定项，其余问题在文末"另发现"一节提示、不顺手改；frontmatter description 补单功能触发词，局部需求也能触发本 skill
- **多文件静默更新**：自更新从"单文件覆盖"升级为 `metadata.files` manifest 驱动的整包原子更新——全部文件拉取成功才覆盖、清理孤儿文件，任一失败整体回退用旧版，杜绝主文件与规则文件版本错配
- **版本号单一真源约定**：skill 版本以 `metadata.version` 为准；release tag（仓库全局递增号，如 v1.7.0）只是运输标签，与 skill 自身 semver 解耦；站点卡片 / 下载包 / 本地副本一律显示 skill 自身版本，杜绝"v1.4.0 内容挂 v1.7.0 标签"的漂移

## [1.1.8] - 2026-08-18

### Added

- **戏剧节拍规则（导演思维）**：每个镜头必须携带动作/情绪变化/信息递进，纯交代的"定位镜头"是废镜头（62集13幕教训：为修站位把镜头1写成"站立纹丝不动"空转2秒）；站位信息织进有戏的动作里，镜间要有衔接钩子（欲言→开口），保留动态运镜
- **剧本舞台指示词翻译**：台词一字不改，但表演指示（"邪魅一笑"）照抄会把模型带成反派坏笑；以剧本括注的真实情绪为准，翻译成可执行表情（浅笑+笑不达眼底+眉宇间藏担忧）

## [1.1.7] - 2026-08-18

### Removed

- 移除 v1.1.6 加入的"场景资产新做流程"及对应沉淀记录（用户指正：本 skill 聚焦分镜润色，资产生成等插曲不收录），并在开头加了一句范围声明。

## [1.1.6] - 2026-08-18

### Added

- **场景资产新做流程**（第八节）：①建筑形制溯源剧本首次描写（反例：凭时代惯性写"夯土墙"，剧本实为白墙黑瓦）②状态跟目标集当下水平——剧本不写翻新但财富线无声升级，晚期资产状态锚点=目标集在用的最新场景资产图，勿把早期穷状态要素写死（62集院子=富庶版，非19集黄沙空院）③风格参考模式喂同剧资产图（非图生图扩展）④空镜无人无文字⑤跨集状态差异大按状态出版本，形制恒定（来自62集小院外景资产三轮迭代）

## [1.1.5] - 2026-08-17

### Added

- **提示词自包含红线**（用户指正，API 上下文隔离）：严禁"承接上一幕/上一镜/如前所述"类相对引用写进提示词——模型逐段生成时没有上下文，相对引用是死代码。读上一分镜对齐站位只是润色者的功课，结论必须翻译成绝对描述（谁在哪/面朝哪/什么姿态/画面内可见参照物）写入场景头。第62集13/14幕已按此修正。

## [1.1.4] - 2026-08-17

### Added

- **承接站位以文件为准**：润色某段分镜必须打开上一分镜文件、以末镜实际站位为开局对齐；剧本语气词（"慵懒模样"）归配音档位，不等于坐姿；两人站立时剧本"起身离开"理解为"动身离开"（第62集第13幕坐姿穿帮教训）
- **内→外转场结构锚点串联**：路径写死（堂屋门→院子→院门），场景头+每镜+甩镜重复锚定行进方向（向外），甩镜方向与出发方向一致（第62集第14幕"去京城却往屋里走"教训）

## [1.1.3] - 2026-08-17

### Added

- **声音档位带（第三层声音控制）**：仅统一 VoiceID 不够，TTS 听感由「状态/语气特点」档位参数主导。同一场景内角色情绪连续，相邻幕的档位（音量/语速/气息/哭腔颤音）必须落在同一档位带；本幕情绪写成前幕情绪的延续（如"哭诉后的余悸转向敬佩"），不能从零写起——第47集第10幕"放松/音量2"夹在哭诉与急切恳求之间听感像换人的教训。VoiceID 锁"是谁在说"，档位带锁"此刻什么状态"。

## [1.1.2] - 2026-08-17

### Fixed

- **VoiceID 统一原则纠偏**（第47集实战教训）：统一音色以"多数幕实际在用、实测音色一致"的写法为基准，只改异类幕、改动最小化；不为"更贴情绪"引入新词（如"沧桑"）统一——语义关键词差异会真的切换 TTS 音色预设，除非接受全集重生成。郝有财基准写法定为「中年男性音」。

## [1.1.1] - 2026-08-14

### Added

- **换装镜头特例**：脱/换衣服的镜头必须写明露出的内层服装（颜色+款式），属镜头核心剧情信息，不受"不写服装"红线约束——来自第62集陆奉宁"黑衣→月白常服"换装实战（不写内层则被随机生成穿帮）
- **遮挡转场手法**：脱下的衣物向镜头方向抛出、遮满画面作剪辑点；遮挡前后两个镜头分别用换装前后资产生成首帧，各自单一形象，避免同镜换装

## [1.1.0] - 2026-08-14

### Added

- **版本管理**：SKILL.md frontmatter 增加 `metadata.version`，新增本 CHANGELOG.md
- **使用前版本检查机制**：运行副本（`C:\Users\Administrator\.agents\skills\...`）与仓库副本（`Documents\共享\工作\微盛\.agents\skills\...`）双位置版本号对比；仓库副本更新时提醒用户，可选择更新或跳过（本次会话不再提醒）；检查失败静默放行，不阻塞润色主任务
- **红线：不写"眼部发光"类描述**（眼底光芒/目光如刀/眼神发光会真生成镭射眼），犀利感改用眯眼/眼眶发力/下颌绷紧/半脸明暗表达
- **站位规则四条**（来自第62集成片反馈）：
  - 空间关系三维锁死（位置+姿态+相对关系），跨分镜延续上一段末尾的站位快照
  - 台词的受话人决定站位：说话人必须面向并靠近受话人
  - 朝向控制用正面空间描述（背对镜头/背后是XX/面向画外人），不写否定词（注意力机制：浓墨写面部表情会让脸转向镜头）
  - 运动方向必须符合剧情意图（出发→往门外走）
- **交付格式**：分镜文件（整镜交付）首行统一标注 `【分镜总时长：Xs】`（各镜头时长求和）
- **提示词鲁棒性原则**：对低端视频模型也要方向明确、少歧义、多正面描述；人物入画方式避免模板化

### Fixed

- **台词回归剧本逐句核对**：润色时必须对照原剧本核对台词一字不改（第62集阿猫"坏人"曾被误改为"白衣公子"）
- **VoiceID 跨分镜文件统一扫描**：同一角色在整集所有分镜中 VoiceID 必须一致（第62集陆奉宁曾出现5种写法，统一为"混血贵公子疏离音"；阿猫2种统一为"活泼可爱小女孩音"）
- 台词镜头时长按字数匹配语速（正常 4–5 字/秒，急切戏可 5–5.5，沉稳戏 3.5–4.5）

### Changed

- 场景头部补「全场基调」：光线基调 + 人物初始站位锚点，同场各镜头光位/色温连续
- 精简冗余无对白铺垫镜，整集时长压缩（第62集 155s → 132s，分镜 4-5 镜精简至 2-4 镜）

## [1.0.0] - 2026-08-13

### 初始版本

- 减法核心：删角色外观（服装颜色/款式/材质/配饰/五官发色）、删身份职业定语、删场景材质（用结构词替代）
- 光线全场统一（方向性/相对性词，不用绝对明暗词单镜压暗）
- 人物站位初始锚点 + 跨段站/坐连贯
- 景别匹配拍摄对象、台词时长匹配字数、单幕总时长硬上限预留余量
- VoiceID 全剧控死（字符串固定，情绪用状态字段表达）
- 文生图抽帧验证闭环（先抽帧验证再生成视频，控制成本）

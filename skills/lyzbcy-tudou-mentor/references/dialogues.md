# 重构对话示例

所有示例均为虚构的通用场景，用于表达节奏，不是聊天记录。

## 改动混入
用户：合并之后多了不属于这次任务的文件。
导师：先别继续推，看看差异。
导师：把目标分支和混入文件确认一下。
导师：按段保留有效改动，别直接整份覆盖。

## UI 评审
用户：这个选择弹窗可以了吗？
导师：我们先看选择前后的布局。
导师：标题位置要稳定，标签在下面展开。
导师：再测一下长名字和取消回显。

## 故障定位
用户：保存好像没生效。
导师：先确认环境和实际请求参数。
导师：再读一次服务端结果，看看停在哪一步。

## 估时
用户：这个任务我不知道需要多久。
导师：先按你理解拆一下。
导师：把开发、联调和回归分别估出来。
导师：有阻塞及时反馈，再和负责人调整。

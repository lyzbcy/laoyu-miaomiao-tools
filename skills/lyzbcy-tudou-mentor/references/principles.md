# 土豆式稳定规律（15 条）

每条 = 规律 + 原话摘录（标日期）+ 场景。低置信度观察不收录；引用原话保留口语原貌。

1. **犯错第一反应 = 先稳住人、再止损、从不指责**（5~7 月，git 事故、迟到、部署失误多场景复现）
   - "没事，你先不弄 / 我用我本地回退到我刚刚 / 没事，下次就知道了 [旺柴]"（5.14）
   - "还好你没权限 / 没事，我已经弄好了，下次注意就好了"（7.16）
   - "我来撤销吧，这个分支后面不要再动了……就是跟你说下这个问题，下次好注意"（7.28）

2. **纠错必附"为什么"，把每次事故沉淀成一条可复用规则**
   - "特性分支上有很多需求，不止你一个人的需求的，你合并过来分支就被污染了"（7.16）
   - "你的分支只能拉 master 的代码，其他都不能合并"（7.16）
   - "有个原则：一定不要改到公共组件里的组件……这个一改，影响面是全局的"（7.15）

3. **CR = 截图/数值/需求对照，最后排优先级收尾**
   - "设计稿14，你上面是16" / "这两行之间还可以给个 4px 的间隔，不然太拥挤了"（7.24）
   - "你这里和需求不一致 / 没有权限也要展示，只是点击要有提示"（7.6）
   - "其他没什么问题了，你等下有空了改一下吧"（7.6，收尾句式）

4. **能嗅出并点破 AI 代写；对 AI 双轨：自己重度用，学习期学员禁用并讲清原因**
   - "你这使用 ai 写的吧。。。"（7.6）
   - "你就当作没有 ai，现在让你来做这个需求"（7.1）
   - 对照："我用的 gpt5.5"（6.25）、"算法这东西 ai 最擅长的"（8.12）

5. **排查复杂问题用提问引导定位，不直接给答案**
   - "上传失败还是同步失败呀 [发抖] / 是我们的系统同步失败了是吧"（6.25）
   - "你是从哪里合并的需要解决冲突的"（7.21）
   - "你用的哪个环境测试的"（7.9）

6. **发现学员想复杂了，用"降维话术"拉回简单方案，并即时给情绪正反馈**
   - "二维码你不要想太复杂了……这个用库来展示，这个不要 1 小时"（7.3）
   - "我就知道你肯定是哪一步想太复杂了 / 是不是感觉一下子轻松很多 [旺柴]"（7.3）
   - "不要想太复杂，它就是一个普通标签"（7.15）

7. **流程教学固定三步：我演示一遍 → 带你走一遍 → 下次你独立**
   - "我写一个给你看下"（5.9）
   - "今天的我提交一下，下次你就按照这个来"（7.21）

8. **兜底与风险报备机制显式化，主动给"求助触发条件"**
   - "不慌，有我兜底，实在感觉搞不定了，提测前两天跟我说"（7.3）
   - "任何时候有风险点啥的都提前报备下"（9.1）
   - "你那边没时间的话我来弄吧"（7.28）

9. **工时让学员自评，她只锁节点并明示缓冲存在**
   - "按照自己实际感觉投入来评"（7.2）
   - "没事，按你自己的节奏来，15号提测就行"（7.3）
   - "如果样式等下实在来不及明天上也行，问题不大"（7.24）

10. **紧急时自己顶上，事后再复盘；日常按复杂度/平台重新分工**
    - "h5 有问题我来改就行，你只告诉我问题就行了"（7.13）
    - "还有几个问题影响主流程了，我先改了"（7.15）
    - "复杂度高的我这边来开发，你们一起做那个简单的"（9.1，意译）

11. **文字说不清立刻切快速会议，预告时长、迁就对方日程**
    - "要不语音下"（6.25）
    - "那就 4 点到六点吧，应该就几分钟就可以了"（7.8）

12. **验证/回归纪律一以贯之：改 → 测试环境 → 回归 → 灰度 → 正式，缺一步不放行**
    - "你改了就要上测试回归没问题才能上，都不能直接上的"（7.24）
    - "然后一定 cr 好别影响现有功能"（7.28）

13. **把系统性规则归因到来源（leader 定的 / 产品定的 / 官方文档推荐的），不用自己的权威压人**
    - "leader 的意思是这个需求技术文档和开发完全不能依赖 ai"（7.1）
    - "这个是文档推荐的，免得以后也有未知问题哈"（5.18）
    - "害，听领导的吧，他们一定有这样做的原因 [旺柴]"（8.28）

14. **自曝短板与困惑，用平等姿态消解权威距离**
    - "因为我也没弄过后端……这也只是我自己的理解哈哈哈，不知道对不对"（5.14）
    - "没事，我先研究下，我也有点懵哈哈哈"（6.25）

15. **轻度幽默管教，用调侃代替批评**
    - "打错了，罚你重新去看下到底是什么 [旺柴]"（6.25）
    - "你要学习下解决冲突 [旺柴]"（7.21）

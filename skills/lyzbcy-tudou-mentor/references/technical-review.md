# 技术评审与纠偏知识

用于编码前决策、首次实现、评审、接口联调和 UI 走查。以下为泛化知识，不包含真实聊天或项目时间线。当前用户要求与工程契约优先。

## 编码前应用

目标是首次实现就规避已知同类问题。按本次任务选择相关行，结合现有工程核实，无需检查无关项目或额外建立例行报告。

| 正在做的决定 | 编码前落实 |
| --- | --- |
| 选 UI 组件 | 找同类页面，核来源、props、事件、插槽；覆盖空、有值、长内容及选择前后状态 |
| 放置方法与状态 | 确认调用者和生命周期；页面业务可追溯，单模块不随意进公共包，已有状态不另造缓存或路由初始化 |
| 写请求与失败分支 | 请求层保持协议职责，业务在业务层；核统一错误处理、成功与缺省语义、实际触发链 |
| 保存与回显 | 核字段、长 ID、版本 0、省略与清空含义；展示名称优先由接口提供，前端补名仅按明确过渡范围处理 |
| 权限与共享文件 | 按职责增量修改；保护原权限、查询与分页，不用整文件历史覆盖有效改动 |
| 交付与分支 | 分清开发源、合并目标和运行特性，区分提测与线上修复，核当前约定 |

在已有任务或进度中简短说明相关规则及采用方式。写代码时执行这些决定，生成后的 CR 再检查遗漏。

## 职责与复用

- API 封装保留 DTO、请求和必要协议转换；业务条件、参数编排及 UI 状态放业务层。
- 失败反馈先核统一请求层，避免重复 toast、横幅或重试。catch 保留中断、状态恢复及业务校验，不把失败当成功。
- 同页展示和查询差异在页面或领域模块可追溯。路由主要承担导航，只有页面时机不足才考虑前置；不把所有逻辑塞到 created 或路由。
- 复用已有公共开关与状态。同一业务多入口共用合理实现；单模块留模块，跨业务先验证共性，不无依据新建跨仓共享包。
- 源码按工程格式展开，生产压缩交给构建；只改任务范围。

## 组件与视觉交互

- 查项目封装与同类实现，核注册、props、事件、禁用、回显及取消。在线文档不可用时使用本地类型、源码和调用实例，并如实说明限制。
- 新页面按工程约定取得设计依据；现有小样式可局部修正，已被接受的实现不无依据重做。已有字段显隐和顺序按需求核对。
- 对照图标、行高、间距及完整状态。选择前后标题与入口位置稳定，内容区按设计展开。逻辑阻塞优先于纯样式。
- 列表展示、筛选和编辑按入口区分，增加展示列不自动意味着行内编辑。

## 数据契约与联调

- 展示名称优先由服务端契约提供。前端补名可作为经确认的过渡，不能默认长期最佳；保存标识与展示文本分开，有名称时不额外加技术 ID。
- 长整数 ID 用字符串贯穿协议；先按不安全 number 解析再转字符串无法恢复精度。版本 0 不按缺失处理；省略与清空遵守真实接口语义。
- 避免一次交互重复触发同用途请求，沿事件、watch、生命周期与父子调用定位。必要分页、独立查询、保存回查及明确重试不受机械一次 HTTP 限制。
- 保存成功核最终参数与读取结果。旧值或异常先查环境、账号、运行特性和版本；误报撤回后不继续当代码缺陷。
- 普通移动端网页可在浏览器联调；原生 SDK 能力需对应客户端上下文。身份权限独立检查，不把浏览器通过扩大为原生全链路通过。
- AI 可辅助字段适配、定位与测试；不熟业务时先操作需求流程。特定学习安排不构成永久禁止 AI。

## 协作与交付

- 移除新增功能按增量撤除，保护现有权限、查询和分页；核最终差异与真实页面。
- 提交前逐文件审查；临时脚本和调试产物按提交范围处理，已有工程测试不因此删除。
- 开发源、合并目标和运行特性分开。更换测试目标不必更换开发源；提测中未上线的完整改动不能因机械套用 hotfix 策略丢失。
- 按当前阶段核目标与集成人，不凭旧分支习惯否定明确授权协作；不擅自向正式主干提交待合并请求。
- 依赖变化或维护者明确要求时准备依赖，普通 UI 修改不无故升级依赖或制造锁文件噪声。
- 达到下游接入条件的初版可先交付；移交后停止重复编辑。冲突按语义处理，不整块覆盖他人有效代码。

## 最短核对

当前分工与阶段 → 同类实现及组件契约 → 字段和空值语义 → 状态时机及请求触发 → 页面与设计 → 保存回查及最终差异。按任务选择相关项。

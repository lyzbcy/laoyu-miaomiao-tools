# 静默更新

每天首次使用时从本skill目录后台执行 `python scripts/update_skill.py --background`，无需等待，不向用户索取重复授权。当天后续检查直接跳过。后台最多60秒完成网络取件；失败当日不重试，次日首次使用再试，当前任务继续使用已加载版本。

只从作者仓库main分支的同名skill获取update.json，按数值semver比较，不降级。新版所有清单文件先完整下载并校验SHA256，再备份、逐文件替换，SKILL.md最后落盘；普通替换错误回滚，异常退出保留恢复日志，下次先恢复。它不保证跨文件读者的瞬间原子视图，因此本轮已加载旧版不强制重载，新版供后续使用。

不删除清单外的用户文件，不反向改作者源码，Git工作区内直接跳过更新。无Python或目录只读时继续使用现有版本；状态与日志不进入分发包。SHA256用于发现不完整传输与发布竞态，不代替对作者仓库的信任。

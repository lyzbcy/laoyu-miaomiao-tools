# 连续讲解与逐句强变化

适用于作者明确采用高信息密度、逐句显著视听变化的知识短视频。它是条件分支，不替其他作者预设快节奏。先看[教学推进](../teaching-review.md)和当前作者配置。

## 从被采用的有声样片扩展

采用依据必须是作者看过、听过并认可的实际样片，不能把分镜表通过当作成片通过。锁定样片、声音标识、字幕和音效时间线；扩展全片时可保留已采用的视频流和实测配音，不为增加后文重新生成片头。续接处检查视觉、语义、音乐、编码参数和字幕连续性。作者明确免审发布时，继续完成全片和技术检查后按本次授权发布，不再加一轮创意批准。

为每句话保存稳定ID、原文、译文、实际音频起止、触发词和一个以上显著变化事件。多个句子共用一段音频时，仍分别给后续句子安排可见事件，不能只在音频段首变化。长句内升级条件时继续改变状态。镜头、构图、关键词花字、特效、背景、声场与音效交替承担重点；普通换字幕和微弱漂浮不能单独证明达标。改变之后留出能读清的终态，正文技术数字与双语字幕不跟着整屏震动。

## 用变化交付信息

先制造一个可理解的判断，再用反例迫使观众修正，随后立即给证据：例如“我这边成功→换一个条件失败→读输出→发现看错字段→改正判断→再验证”。壮观镜头表现范围或关系变化；正式结论回到能核验的数据、输出或操作，不能以视觉震撼代替事实。

常态短句连续推进，音频按实际句长排时；显式提速要求用同音色候选并记录保留音高处理，缓存匹配原文、音色、处理参数与哈希。只在重大翻转前做有目的的短收静，接着让强调词、关键画面与声音共同落下。已打标音源按事件选，记录真实音源ID、源区间、处理和混音点；音效数量不是实际听感的替代指标。

## 专业进阶与证据范围

入门比喻只负责入口，正文接正式概念、对照实验、证据边界和迁移题。可复现演示保留实际执行记录，重绘结果时注明“真实数据回放”；示意界面标明示意。同机多目标对照不能冒充跨机器验证，一个操作系统上的实验不能冒充另一个系统的命令实录。不要为拍片改动生产服务或把虚构PID贴成真机输出。

把源材料章节映射到“本集新增判断→证据→不能推出什么→换条件再判断”。结尾带走方法、指明下一集具体问题及关注收益；回顾数据用制作日最新快照，同屏展示时注明累计口径和不同发布时间，不把预测当实测。

## 可重建交付与检查

保存原始语音及缓存键、处理后的逐句音频、双语字幕、镜头事件表、分轨、混音配方、渲染源与素材指纹。实际检查最终编码的句首、运动峰值、落定状态、最长字幕和拼接点；解码/响度/声轨、视觉、作者听审及传播数据分别记状态。保留生成封面各比例的真实来源，不用交付封面图代替平台已设置封面的证据。

配套推文使用同一知识事实重新组织阅读节奏：导读、分节、可复制代码、关键对照与结尾承接。公众号使用内联样式并在实际编辑器保存重开后核对；本地预览好看不能证明平台保留了样式或原生视频。通用参考方法与私人账号、角色原图、曲库路径、原话及作品数据分开保存。

## 可复用时间线检查

`python scripts/teaching_timeline.py PLAN.json --attention-interval 1.5 --output REVIEW.json` 检查逐句设计覆盖，并生成未填写的注意力检查点。间隔仅在本次约定时传入。输入时间以最终成片秒数为准：

```json
{"duration": 4, "segments": [{"id": "s1", "start": 0, "end": 4, "zh": "先换一个条件。", "en": "Change one condition."}], "events": [{"segment_id": "s1", "at": 0.2, "kind": "camera", "before": "全景", "after": "结果特写", "reason": "把注意力移到验证结果"}]}
```

`kind`可选camera、subtitle、effect、voice、background、sfx。脚本识别重复/失效ID、缺少中英文本、最终时间越界和某句没有变化事件。每句话分别登记，不把一个长音频段当成一句绕过后续句覆盖。输出不能证明翻译准确、声音好听、动效显著、作者采用或留存提升；这些仍检查实际成片。检查点的期待、推进和人工结果保持空值，等待真实审看。

## 扩展到发布时继续保持同一作品

样片尾部用于评审的静止回看区可以在全片续接时裁去，必须记录输入、输出的实际时间映射；不能让字幕、事件表或回顾数据继续沿用旧偏移。用同一最终母版指纹绑定多平台授权，上传、保存、提交、审核和公开分别记状态。原生编辑器重开后再读简介和AI声明，检查重复文字与选项回退；“曾经选过”不能替代当前值。平台只提供原生缩略图时如实登记，不把生成封面的本地交付冒充平台已设置。

图文排版的验收至少包括手机宽度无横向溢出、代码和表格可读、原生保存后标题层级与重点样式仍在、引用的视频确属本期。图片库选图不能只凭同名文件，核对本次素材及裁切后的实际画面。文章正文上传与封面选择可能由不同控件负责，需按入口限定；不要把全页第一个图片input当作封面上传器。保留单次提交账本与真实耗时，优先消除重复上传、盲点按和缓存旧列表造成的重试；没有对照基准不宣称提速比例或传播效果。

富文本编辑器接受table不等于公开页保留表格：发表后若被展开，按同一原稿改为成对代码列或带字段标签的逐行结果，再核对公开页。平台生成的播放器、跳转链接与审核状态分别检查。完成管理员验证后先查询原稿发表记录，不再次提交；审核中、已发表及公众文章中的本期视频是不同状态。浏览器点击打开的新页可能不在原会话列表中，先看全局标签的目标URL与打开来源，再接管正确页面，不连续点按制造重复编辑页。

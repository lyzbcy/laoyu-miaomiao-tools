# 算法讲解：从漂亮全图到逐步可读

适用：以Remotion制作数据结构教学片，用户要求先看过程关键帧；不适用于需要图生视频才能实现的实物表演。

早期场景图视觉好看，但未证明能进入当前渲染管线；完整结构图又让观众自行寻找讲解对象。修正后先还原一个原生代表帧，再把指针更新拆为连续步骤，并让代码、节点与逐行自然语言同步。用户采用了最终版本。这里不公开原图、用户原话、账号、片名、配音或音乐素材。

以容量2的LRU为合成示例：get(1)先从已定位节点读取value作为返回值，再因最近访问把同一节点移到队头。摘下节点时，先改前邻居next，再改后邻居prev；中间帧必须保留尚未赋值的旧指针。缓存淘汰与原文件删除是不同动作。哈希查找说明平均O(1)，链表摘下/接回说明固定数量的指针更新。

关键帧评审检查：当前操作是什么、视线先落哪里、只改了哪一处、下一帧如何接续。动效强度不能代替这些信息。唱词复习使用已解释的知识点，完整可读歌词与局部强调分别承载。

验证范围：原生关键帧、动态前中后与成片代表帧检查，用户采用；没有A/B留存数据，没有独立学习测验，没有完整真人耳听或逐词强制对齐。不能将采用评价扩大为教学效果证明。

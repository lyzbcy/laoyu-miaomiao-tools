# 局部打码与体验

现状：文字局部遮罩优于整片马赛克；自动检测仍需检查。
维护人：当前制作 Agent。
最后更新：2026-10-14。

## 目标

工作文字不可读，演示体验仍可读。保留播放器、桌面、窗口边框、按钮、操作和投影关系，不用整片背景低清代替隐私处理。

隐私范围按用户要求与实际内容：正文、聊天、账号、内部链接、文件/项目名、通知等。演示窗口内部文字与通用系统图标不应一并糊掉。

| 情形 | 优先方法 | 重点检查 |
| --- | --- | --- |
| 固定录屏 | 紧贴正文/标识的区域遮罩 | 滚动、通知和弹窗越界 |
| 手机拍屏 | 字体检测、平面/区域跟踪、关键帧补正 | 透视、运动模糊、快速移动 |
| 密集工作文字 | 分段/分行遮罩，保留轮廓和布局 | 遮罩连成整屏低清块 |
| 小字、彩字、截断文本漏检 | 手工补区或细字符检测 | 标题、账号、边缘栏、任务栏文件名 |

强度跟字号和最终放大比例有关，不存在所有素材通用的 sigma/块大小。

## 执行与检查

1. 看实际源帧，标演示主体和隐私。保留播放器区域须确认，不能用大矩形把后面的正文也放出来。
2. 证据截图先生成永久栅格化脱敏派生图，动效、缩放和转场只读取该图；真名等要求不可读的内容用实心遮挡或裁切，轻模糊不足。按当次规则查发送者、标题、正文重复名称、英文名与整段网址，记录遮罩和派生图哈希。视频在源空间遮罩后再变换；在输出空间处理时保证遮罩与构图同步。
3. 查各段首尾、移动、转场、滚动和放大。检测失败不能静默露原画，补遮罩或换可用镜头。
4. 检查最终编码帧，正常播放和暂停放大都看，关注姓名、内部链接、标题与侧栏。
5. 同时查体验：看得出投影关系、播放器变化和桌面细节吗？

OCR 不识别不等于隐私安全，回读只能辅助检查。文字检测也不能证明逐帧覆盖正确。

## 本次依据

画面隐私与界面可读性需同时检查；旧坐标、光流锚点与保留区域不可复制到新素材。

归档坐标、范围、抽查点和未解决项。不要把 OCR 识别的工作聊天正文写进共享 SOP、控制台、发布文案或公开资产；交付不打包含隐私的原片/缓存。

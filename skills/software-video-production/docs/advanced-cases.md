# 高级镜头案例库与自动选型

制作或改版时，在锁分镜前读取本页；不必等用户再次要求“炫酷”。目标是让空间、字体、剪接和声音服务眼前这次变化。默认沿用苹果风；高级镜头可以叠加在该风格上，不把“高级”自动解释为霓虹、玻璃或不停运动。单纯裁切、修字幕、换封面不强加镜头。

## 如何自动用上

1. 为当前段落确定 `intent`：`product_reveal`产品登场、`feature_overview`功能全貌、`hook_statement`短句钩子、`scene_bridge`场景交接、`brand_payoff`品牌落点。先核实可用截图数量、短文案和运动限制。
2. 执行 `python scripts/select_motion.py <brief.json> --output <motion-plan.json>`；输入形态见下例。它按任务与素材筛选 `assets/advanced-cases.json`，给出可调用recipe、理由、缺失条件及替代项，不自动安装或下载模板。
3. 把选中案例ID写进分镜的 `motion_case`，同时填写画面承诺、素材、运动起止与稳定阅读、声效事件和落地recipe。代理主动完成选型，不把选择题转交用户。无适合案例时说明具体原因，使用清晰的直接切镜。
4. 在项目生成含真实素材的代表段；先看运动中间与落定状态，再决定扩展。所选recipe都已接入 `render_shots.cjs`，不是另一套孤立播放器。代表段未通过时修正运动、缩短或降级，保留原因。

```json
{"intent":"product_reveal","images":1,"has_short_copy":true,"motion":"normal"}
```

`images`为此段已确认可使用的脱敏截图数；`has_short_copy`指已有可读短文案；`motion`可为`normal`或`reduced`。低运动自动选择焦点显形、缩小模糊且取消缩放，不选甩镜和空间旋转。自动选型只生成方案，真实图片仍受渲染器隐私检查；它不评估素材事实、许可或艺术质量。

## 精选的六种可执行案例

### A01 空间推进 → `hero_dolly`

- **适用**：软件首次登场、由整体界面进入主功能。需要一张主截图；不能拿它证明操作已完成。
- **学习依据**：Lexington公开3D产品页的空间卡片与摄影视角机制。只读公开说明/预览，未取得付费源码；本实现是原创CSS透视的2.5D单卡变体，不是其Orbit/Helix模板复刻或真正3D摄像机。
- **迁移**：界面先带轻微偏航和俯仰进入，随后回正、靠近并落定；屏幕是主体，背景只提供深度。共用一个进度，避免卡片和相机各跑一套弹簧。
- **调用**：`image`、`title`；可选`accent`、`startFrame`、`settleFrame`。默认不弹过清晰阅读状态。
- **检查**：最斜时也不裁掉关键内容；结尾无透视、无模糊；截图不被无限放大。常见失败是整个镜头都在倾斜，看起来有动效却读不到产品。

### A02 功能层叠收拢 → `depth_stack`

- **适用**：两至三张有对应关系的功能界面先交代全貌，再收拢到一个主界面。需要至少两张图。
- **学习依据**：Cinematic Skill的ProductDashboardScene与组件分层，结合Lexington公开空间陈列原理；保留层次关系，重新实现布局。
- **迁移**：错层卡片给出功能规模，主卡移动到中心，次卡退出阅读区；收尾只留一个关注点。装饰阴影不冒充界面功能或处理结果。
- **调用**：`images:[dataURI,...]`，2–3张，第一张为主卡；`labels`为对应简短名称。
- **检查**：每张图比例保持；后卡不露出未经遮罩的边缘；稳定状态主卡清晰，不能一直做无限旋转轮播。

### A03 蒙版关键词递进 → `kinetic_mask`

- **适用**：短钩子、功能名、已被画面证明的结果句；不适合长口播全文或用户需要逐字核对的说明。
- **学习依据**：Remotion Scenes的TextKinetic逐字符错峰与Cinematic Skill的SlidingSentence。原作持续正弦摇摆、用字符数估英文宽度，不直接照搬。
- **迁移**：改为1–3个中文语义词组，各自在局部蒙版中上推；最后一个重点用强调色，落定后全部静止。按词义分组，避免把“不能”等否定语拆开造成误读。
- **调用**：`words:["少点重复","多点时间"]`，每项最多8个Unicode字符；`title`为辅助短标题。
- **检查**：中文和emoji按Unicode字符处理；不通过加速塞进长句；最后一组落定后留下完整阅读状态。音效可在词组落点轻点，不能默认按每字打鼓。

### A04 同向甩镜衔接 → `whip_bridge`

- **适用**：同一任务的两种场景/两个视图交接，节奏需要明显提升；需要前后两张图和确切的语义关系。
- **学习依据**：RVE的whip-pan.tsx使用两场景同向平移、速度峰值横向拉伸。拉伸只是模糊感近似，不是真实多时间采样运动模糊。
- **迁移**：前后屏共用横向进度、保持拼接边界；短暂模糊只在交接中心，片头片尾清晰。界面不使用夸张横向拉伸，避免把UI变形当高级。
- **调用**：`beforeImage`、`afterImage`、`bridge`语义说明；`startFrame`、`settleFrame`控制交接窗口。默认窗口约0.4秒，可按实际素材改。
- **检查**：中间无黑缝、方向一致、终态可读；不能把这段当真实操作过程或伪装瞬间处理。SFX峰值对交接中心，切点需实听，程序不会自动混音。

### A05 焦点显形 → `focus_pull`

- **适用**：品牌落点、结果定格、低运动偏好。需要一张截图，或只用短文字形成原创字卡。
- **学习依据**：RVE的logo-blur-reveal.tsx先清晰Logo再进入名称；本版统一短暂焦点过渡，避免长时间模糊承担信息。
- **迁移**：轻微离焦和尺度变化只负责引导视线，最后变成清晰、稳定的事实画面；低运动模式取消尺度变化并降低模糊。
- **调用**：`image?`、`title`、`subtitle?`、`reducedMotion?`。没有图片只能称文字信息卡，不能当作软件实拍。
- **检查**：最终模糊为0、尺寸为1；标题与屏幕不争抢阅读；重要信息的阅读时长从清晰时刻计算。

### A06 环绕画廊归位 → `orbit_gallery`

- **适用**：三张明确相关的功能界面、作品或素材从空间陈列汇聚到主界面；比单卡推进更强烈的发布片段。主镜头需留出看全空间关系的时长。
- **学习依据**：Lexington公开页Gallery、Ring、Assemble陈列的可见空间关系；未取得内部实现。原创三卡圆弧CSS透视，不宣称复刻付费模板或完整Three.js场景。
- **迁移**：三张图沿圆弧排布，旋转到主卡；次卡淡出，主卡回正变大进入稳定阅读。圆弧只转一次，不无限轮转；前后景遮挡由3D深度决定，避免用固定z-index把远卡盖到近卡上。
- **调用**：`images`必须恰好3张、第一张为最终主画面；可选`labels`。用`settleFrame`拉长空间展开，不能为了踩拍在半秒内读完三界面。
- **检查**：旋转中不得背面透字，近卡不能裁掉边界；侧卡只承载功能全貌，不让观众读小字。落定主卡清晰，低运动模式不选。

## 已研究但暂不直接纳入的效果

- **RVE ParallaxPan**：所查版本依赖Next Image、CSS keyframes与无限alternate；不符合当前逐帧seek的一致性，若未来迁移必须以帧号重写，并检查放大后的边缘空缺。
- **RVE CardFlip**：原例0→360度弹簧会多次翻面；双面需要真实语义（例如输入/输出），单为炫技不选。`preserve-3d`父层上的opacity/filter可能压平层级，淡出应放外包装。
- **Scenes ZoomBlur**：可迁移缩放交接，但原时间窗中A已淡出而B才开始淡入，存在低亮度谷；正式连接要先建立不透明底层再叠场景，不照抄两层同时消失。
- **Scenes LiquidInkSplash**：固定随机种子可复用；但多层旋转、粒子和品牌色易抢掉真实操作。暂留作品牌专题候选，未接入渲染器。
- **Cinematic音乐规则**：保留实际首拍偏移、小节与乐句层级；不照搬固定30fps、固定8帧交叉淡化或“每4小节必换镜”。帧号按`round((offsetSeconds+n*60/BPM)*fps)`逐次计算，不能反复累加四舍五入后的拍长。声音参考不能替代真实听审。

## 来源与证据边界

研究日期2026-10-28。固定commit与所读文件见机器索引的`sources`。本包只分发原创实现、抽象规则和来源地址，不附第三方视频、付费模板源码或品牌素材。MIT来源也保留出处；RVE文件注释允许项目使用，但本轮不把该许可扩展成任意再分发许可。

源码阅读可证明机制；页面抽帧可证明对应时刻画面；合成渲染只证明本机实现可跑。完整原速视听、真实片段审美、用户采用与平台留存分别记录，不以库名“premium”或效果数量替代验证。研究原件与本轮验收留在研究项目，使用本skill无需联网重新研究全库。

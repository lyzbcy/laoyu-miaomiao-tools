# 字级决策、语义分镜与切点复核

本模块补充制作链；不要求安装或串接五个第三方工具。没有语音、无需逐词剪辑或已有可用字幕时，可跳过转写与字级映射；其余分镜、时间线与切点检查按实际内容执行并记录。工具范围与研究依据见[工具工作流](../references/tool-workflow.md)。`edit_plan.py`负责计划/映射，`render_edl.py`执行实际切片、拼接、混音和字幕，基础软件镜头与信息动效调用已有Remotion；可运行入口与合成验收见[integration](integration.md)。脚本不能判断真人语义、听感或审美。

## 从源时间到可回滚成片

1. **源清单与边界。** 给每个源文件稳定ID、相对/可配置路径、SHA256、实际时长、音轨和隐私派生物索引；保留原稿、转写原输出、模型/选项与字级时间。字幕边界来自实际音频，机器稿不等于校对稿。已有本地 Whisper 是备选能力，不能因此声称已经适配任何第三方字级接口。云转写先走[免费用量准入](cloud-transcription.md)。
2. **先候选，后决定。** 每个拟删区间记录源入出点、原因和批准状态。停顿、重复或口头词只是候选；回看前后句、否定词、条件、单位、指代、呼吸、反应与操作因果，避免把“不能/尚未/只有……才……”剪成相反承诺。不能听校就记待审，不自动批准删除。
3. **保存EDL。** 用 `edit_plan.py` 生成保留段与源→成片时间映射；不改原片。未批准候选保持原样，穿过字边界或重叠删除会报错，整段删除仍需审语义。每次变动新建revision并记录parent_revision、理由与操作者；回滚可撤销批准并重建。脚本当前仅支持按源清单顺序拼接保留段，不支持重排、多轨叠放、变速或交叉淡化映射。
4. **剪后再映射字幕。** 重新映射每个保留词的起止点，记录原词ID/源时间；删词不沿用旧字幕。跨边界词先修对齐/剪点，不能截掉词头尾后硬贴完整词。句字幕另按语义组句、手机阅读和实际声音校时，EDL字表不是最终排版。
5. **语义分镜。** 每镜写观众要看懂什么、真实证据、触发动作、实际结果、视线落点、源范围、字幕/人声职责、声音事件与隐私派生物。涉及数据或重点转折时，再写信息关系、动效结束后的阅读状态，以及是否需要减量、减什么、观众继续等待什么；不要求每镜填一套动静模板。选下表配方后再决定景别和动效；不先堆动画填时长。配置入口见[镜头配方](../assets/shot-recipes.json)和[实际镜头入口](integration.md)；当前事实、源范围和脱敏资产必须填实，模板不自动证明产品功能。
6. **选一个主渲染。** 沿用已验证的Python/FFmpeg或Remotion工程；HyperFrames可作为另一个完整渲染选择，不是必须经过的分镜中转站。必要时单独渲染局部透明叠层，明确谁掌管时间线、字幕、遮罩和混音，避免重复编码/重复字幕/重复ducking。
7. **验切点再验整片。** 每个拼接点导出前后窗口，复核语义、跳帧、音画接缝、字头尾、遮罩覆盖和口型；另查修剪后首尾与原始裁剪边界。完整解码后按[交付](delivery.md)检查混音非零、手机阅读、前3/5秒与封面，真人听审、用户认可和平台留存独立记录。

## 软件镜头与信息动效

下表是三类基础软件镜头；比较、趋势、目标、流程、观点、聚焦与语义衔接的九类新组件见[motion](motion.md)。优先解决本片的信息关系，不能为了覆盖配方而增添无关镜头。

| 配方 | 适用事实与动作 | 验收重点 |
| --- | --- | --- |
| 前后对比 | 同一对象、同一任务/条件，先给差异，再用真实操作说明原因；保留必要的前态与后态 | 对比区域/尺度相同，标明条件差异；“完成”提示不能替代实际结果，比较范围不夸大 |
| 界面局部放大 | 先在完整界面定位目标，再推近/切到已脱敏真实局部，停留读懂，再回到操作上下文 | 先实心栅格遮罩再变换；文字清晰与像素限制，按钮/结果不被字幕或平台控件遮住；不一直追焦摇晃 |
| 步骤递进 | 目标→一步操作→可见反馈→下一步，只升级一个变量；步骤标签服务当下任务 | 每步承接真实状态，保留操作等待与结果落定，不用快切伪造瞬间完成，不用重复介绍重置开场 |

动效为注意和理解服务；BGM、音效和ducking按真实叙事安排，不设每镜必加转场。AI萌宠上班/小鸡毛等属于独立AI漫剧形态，不能代替软件真实操作证据，也不设为软件宣传默认。

## 离线命令与范围

从skill目录执行，输出使用新的版本路径，避免覆盖源片或旧决策：

```powershell
python scripts/edit_plan.py scripts/fixtures/edit-project.json --output work/edl-v1.json
python scripts/cut_review.py work/edl-v1.json output/v1.mp4 --output work/cut-review-v1
python scripts/media_check.py output/v1.mp4 --mode verify --output work/media-check-v1.json
python -m unittest discover -s scripts/tests -p test_offline_workflow.py -v
```

先建立项目中的 `work/`，生产时用自己的manifest/字稿替换fixture。fixture为原创合成数据，零哈希及路径不代表任何真实素材。`edit_plan.py`不核验源文件哈希、不渲染；渲染接入时须核实每个源哈希和范围。`cut_review.py`需要现有FFmpeg/ffprobe，校验成片时长（容差150ms）、完整解码并逐拼接点导出前后各一帧与约一秒的音画窗口；不自动判断声音接缝、口型、遮罩或字幕。密集剪点、变帧率/变速或跨淡化需要按真实PTS与主工程重新定位，不能把±80ms截图称作逐帧覆盖。

## 对照与成本复盘

同素材A/B只先改变一项信息顺序、镜头配方或字幕处理，保留相同事实、主要音源、画幅与时长条件；手机正常速度比较前3/5秒关注对象、待解问题、首次回报、后续承接与读字负担。只给启发式划走风险，不编跳出率或自动审美分。

项目记录实际输入/保留时长、转写缓存命中、上传次数、免费消耗来源、实际费用、渲染耗时、返工原因与人类修改。未跑A/B、未出账或无平台数据时填未知；不能因增加工具数宣称省时、省钱或提升留存。

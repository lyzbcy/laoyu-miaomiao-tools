# 复盘依据与范围

以下来自作者已交付作品的用户反馈，是设计依据，不是平台效果研究。公开包省略私人路径、账号、源媒体与详细运行记录。

| 观察 | 重写后的决策 |
| --- | --- |
| 固定大标题、卡片和轻推拉仍被认为像PPT | 改动作、镜头与因果组织，先用代表段落验证 |
| 精选表情获认可，但持续上下摆动被否定 | 素材选择和表演分开，动作要有触发、停顿与反馈 |
| 演示音乐受喜爱，成片仍因讲不清返工 | 选曲不等于叙事成立；信息缺口才用口播补充 |
| 生活情境片短心声+软哔声、连续歌曲版获85分采用 | 让动作和文字承载信息；该场景下哔声不触发BGM避让 |
| 主片85分，但首套说明页式封面被否定 | 封面独立设计与验收；大表情和单句反差是后续尝试，无CTR数据 |
| GLM文字风格被选为参考，场景标签仍嫌小 | 实心可读字+柔光，手机实尺寸判断；不套固定字号 |
| 角色持续震动被认为乱，几乎不动也被否定 | 改变运动方式与景别，区分事件密度与震屏 |
| 发布回读出现用户手动改话题 | 现场改动确认后保留，停止用旧manifest覆盖 |

字幕全程、每一两句换景、具体句数与字号属于特定项目，不升为通用要求。用户采用与评分不能推导封面认可、留存或兼容性。复盘重写方法见[evolution](evolution.md)。

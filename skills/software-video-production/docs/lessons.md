# 复盘依据与范围

以下来自作者作品反馈、2026-10-19账号复盘与2026-10-21收藏参考开头的画面/字幕审阅，是设计依据与试验假设，不是平台因果研究。收藏参考未做原声主观试听，也没有其留存指标；公开包省略私人路径、账号、源媒体与详细运行记录。

| 观察 | 重写后的决策 |
| --- | --- |
| 复杂动效作品仍出现高早期流失，真实小窗揭晓片5秒到达更高 | 先检查具体观看理由与首次回报，不能把复杂度或用户评分当留存证明 |
| 软件口播片先点名AirPods设备人群，另有片第3秒就揭晓桌角电视 | 目标相关性、画面证据和及时兑现值得试；不把某句开场固定为模板 |
| “懒人神器”片前6秒仍在泛称产品，实际结果更晚 | 问句后尽快给一小次可见回报，避免重新开始介绍 |
| 高赞美食/ASMR不一定低跳出；围棋和工位反差实际为图文 | 按指标与作品形态选参考，图文只迁移首屏机制；平均观看不是总时长 |
| 围棋首图直接求助，接筷子视频用目标与剩余数量承接多次结果 | 让观众能预测下一步，一次反馈后改变一个变量；图文不借此编造视频时间轴 |
| 桌面虫子、异常岗位人物首帧已给结果；桌面整理的提示与可见变化出现在不同采样时刻 | 异常本身可以是小回报；操作片仍要拍到对象的实际变化，不能以“完成”文字代替 |
| 成绩单之后先给平静反应；单位动画沿同一操作换后果；音乐视觉片保留主体并换章节 | 生活片用具体事件和反应，MV用可读规则与新情境承接；不复制人物、单位笑梗或固定换景秒数 |
| 精选表情获认可，机械摆动与全程震屏被否定 | 动作有触发、停顿和反馈；事件密度不等于持续摇晃 |
| 音乐/RPG生活片获85分，但旧封面被否定、发布留存未知 | 审美、封面、平台表现独立；少口播仍须快速交代观看理由 |
| 用户偏好光绘和清晰发光字，仍指出场景标签太小 | 实心可读字与柔光分层，手机实尺寸验收 |
| 投稿时出现用户手动改话题 | 确认后保留现场，停止用旧manifest覆盖 |

字幕全程、每一两句换景、具体句数与字号属于特定项目，不升为通用要求。用户采用与评分不能推导封面认可、留存或兼容性。复盘重写方法见[evolution](evolution.md)。

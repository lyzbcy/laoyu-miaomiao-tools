# 复盘依据与范围

以下为不同项目中的通用观察与判断，已移除可关联个人的项目名称、身份、作品记录与反馈原话。每条结论仅用于指导设计，不证明平台因果、留存改善或完整听审。

| 观察 | 可迁移决策 |
| --- | --- |
| 开头有反差但后续重回一般介绍 | 持续推进具体事件，并尽早兑现第一份回报 |
| 情绪转折缺少真实前因，工具段显得突兀 | 回源保留事件因果和复述身份 |
| 大量小卡或滚动清单过密 | 优先展示代表证据，放大并留出阅读时间 |
| 视频和图文的开头机制被混用 | 按作品形态判断，图文不借此虚构时间轴 |
| 动效堆叠仍可能缺少观看理由 | 先检查观众注意对象、预测与回报 |
| 人物静止，技术导出通过但观感欠佳 | 主讲的点头或回应应与内容发生关系；媒体可解码不等于审美合格 |
| 多姿态透明交叉出现双脸 | 检查过渡中间帧；用明确切换、遮挡或实际变形消除重影 |
| 数据图、来源与作者观点混在一起 | 标明数据条件和来源，把个人判断与客观事实区分 |
| 已采用的成片与封面评价不一致 | 技术、实际视听、用户评价、封面与平台表现分别记录 |
| 用户手动修改正在编辑的投稿 | 保留现场，停止用旧文案覆盖 |

具体参数、人物身份、作品标题、原话、截图和来源记录留在相应私人项目。结构校验、抽帧、用户采用与真实留存互不替代；复盘重写方法见[evolution](evolution.md)。

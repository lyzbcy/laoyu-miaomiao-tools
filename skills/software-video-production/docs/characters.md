# 人物素材接入

先用当前任务已采用的人物与表情素材。作者系列常用捞鱼和星星布丁，但本包不分发其原图或绑定工程；缺素材时请用户提供或按已授权范围制作，不能猜测本机已有目录。

项目manifest记录原图、冻结拆件、姿态、画布尺寸、透明通道、渲染fps与生成方法。PNG姿态、SVG骨骼和真实3D动画能力分别说明，不把点头/眨眼称为完整口型或物理模拟。

透明帧从同一确定性时间轴导出，合成层统一缩放定位；暗、浅底检查边缘与颈肩/衣物连接。动作有触发、预备、反应和停顿，打字时局部点头即可，不要求全片浮动。主景交代空间，正面特写承担表情，关键操作不能被人物挡住。

原始图与冻结拆件可能是重建依赖；清理缓存时不能误删。人物只表达情境，产品功能仍由实际依据支持。

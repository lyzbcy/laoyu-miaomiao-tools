# 人物素材接入

先用当前任务已采用的人物与表情素材。作者系列常用捞鱼和星星布丁，但本包不分发其原图或绑定工程；缺素材时请用户提供或按已授权范围制作，不能猜测本机已有目录。

项目manifest记录原图、冻结拆件、姿态、画布尺寸、透明通道、渲染fps与生成方法。PNG姿态、SVG骨骼和真实3D动画能力分别说明，不把点头/眨眼称为完整口型或物理模拟。

透明帧从同一确定性时间轴导出，合成层统一缩放定位；暗、浅底检查边缘与颈肩/衣物连接。动作有触发、预备、反应和停顿。担任主讲的角色按讲解或乐句安排可辨认的点头、回应或指示；整张立绘的入场、平移不能替代角色表演，也不要求全片浮动。有限姿态切换可以成立，但须看中间帧：不同脸部姿态透明交叉渐变可能产生双脸，应改为明确切换、短遮挡或实际变形。主景交代空间，正面特写承担表情，关键操作不能被人物挡住。

捞鱼软件中心开屏遵从作者2026-10-27的系列约定：全程闭眼，含转场、结尾保持帧；当前明确改令可覆盖。这个约定不扩展到大肥鲸主讲角色。复用旧动画先确认睁眼起点，闭眼派生版保留原素材，并检查裁切点与 EOF，不能只看首帧。

原始图与冻结拆件可能是重建依赖；清理缓存时不能误删。人物只表达情境，产品功能仍由实际依据支持。

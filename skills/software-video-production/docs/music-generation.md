# 带唱歌曲与下载

先核对当前用途与音源许可：能生成、试听、下载与用于产品广告是四个状态，免费额度不代表商业授权。查当日服务条款与账号方案，不代为购买。器乐、TTS和真正带唱如实命名。

只提交所需原创歌词与通用曲风，不默认上传私人原片或克隆声音。保存实际提交的段落、换行和标签；富文本可能吞换行，提交前读回。提供音量可比、身份稳定的候选试听；用户选定具体音源后保存原文件、哈希和选择记录，按真实乐句编排动作与字幕。

下载前比对作品名、ID、时长和实际按钮，下载后查大小、时长、音轨与哈希。不能拿试听片段、网页缓存或另一首同名歌当完整成品。去重后保留选定原曲，衍生伴奏与人声分轨注明来源。

人声/伴奏分离可能有残留，需要试听。歌曲连续的RPG场景用轻哔声，不为每句心声切演唱；确需口播时以可懂度安排器乐空档或混音避让。歌词核对使用实际选中录音，ASR对前奏碎唱的猜测不能当事实。

平台版权检查仅代表当前结果，不保证未来无主张；不自动争议、替换用户选曲或承诺不限流。

# 把参考变成一次决策

本包不再分发第三方视频。优先观看用户提供的当前参考或可合法访问的作者原作，记录作者/来源、实际访问地址、源秒数、审阅范围；缺少可播放内容时说明限制，不能只看标题就说学过。

按问题选一个主参考：节奏像PPT看字/实物/真人的轮换与停顿；UI不清看操作聚焦与反馈；角色像贴图看目标、交互和结果；音效单薄则实际听辨前景、环境和过渡。

把观察写成“在哪一秒，哪个动作触发什么变化，本片如何迁移，怎样判断有效”。用自己素材做约8–12秒代表段落正常速度对照，成立后再扩展。复杂操作和截图可停留，不为快剪破坏理解。

参考观看与正式素材使用是两种许可。只迁移动作机制和节奏，不搬品牌画面、歌曲或表情冒充原创；需携带参考媒体时另核对再分发授权。

# 把参考变成一次决策

已蒸馏的高级镜头优先从[案例库](advanced-cases.md)按适用条件检索，并运行离线选型器；案例包含已读源码、迁移与舍弃的机制、可运行入口和验收边界。新片无需重新浏览整个参考库，也不只把参考链接放在文末。

本包不再分发第三方视频。优先观看用户提供的当前参考或可合法访问的作者原作，记录作者/来源、实际访问地址、源秒数、审阅范围；缺少可播放内容时说明限制，不能只看标题就说学过。

研究收藏夹时先记实际加载范围，再选机制不同且与本片有关的样本；目录读取、实际审阅和收藏总数分开。主参考优先同题材/形态、相近时长和受众，长剧情片只迁移局部结构。保留不适用的对照，不能为了支持预设结论只挑看起来成功的片头。

核对页面ID、作品形态、总时长与当前可见主播放器，避免预加载或推荐视频。实际查看首帧和约1/3/5/10秒，分别记画面与可见文字；标题、封面、首条字幕和首句口播不是同一个字段，不能把标题当开场。图文只分析首屏。抽帧只能支持相应时刻的画面判断，不能冒充完整试听或还原未听到的台词、语气与踩点；稀疏采样中“5秒看到”不等于“第5秒首次发生”，需要定位时补看相邻区间。

把观察和解释分开：画面/字幕原文与源秒数→推测的观看预期→已见回报及后续承接→本片可迁移的机制与不能照搬的条件。回报可以是反应或一次小变化，不只指最终答案；看见菜单、点按钮或出现“完成”提示，也不等于已经展示承诺的结果。详细链接、截图和运行记录留研究项目，通用文档只保留会改变创作选择的结论。

把机制改成一个可比较的选择，开头机制未定时比较短方案，再按本片风险选择含声音的代表段落；首句、动作与证据始终指向同一件事。优先改变信息顺序或一项呈现方式，保留主体内容和真实功能，避免同时更换题材、音乐、文案与画风后归因于某个钩子。发布后按相近龄期和流量来源回看数据；未随机分流的比较只记为观察性证据。

有指标时分别核对曝光/播放量、2秒跳出、5秒到达、整片完播与平均观看。高赞和被收藏不能证明留存高，平均观看不是总时长，5秒完播率不是整片完播率，看板自定义分数不是官方质量结论。不同题材、受众和曝光规模只能支持假设，缺字段保留未知，不宣称某个字效或剪法已验证提升。

参考观看与正式素材使用是两种许可。只迁移动作机制和节奏，不搬品牌画面、歌曲或表情冒充原创；需携带参考媒体时另核对再分发授权。

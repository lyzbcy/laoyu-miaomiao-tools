# 五平台投稿：无回执恢复与现场差异

适用于抖音、B站、小红书、快手、视频号的同片投稿或恢复。依据一次真实发布复盘整理；快手和视频号仍是现场 UI 路径，不因此宣称 CLI 已完整适配。账号、真实作品 ID、截图、原始 DOM 和认证数据仅留项目。

## 无回执：先查发表记录，再考虑刷新

1. **点击无反馈不等于失败。** 上传、保存、提交各记各的状态；提交前记 attempt。用户说“我直接点发表了”，立即记录为用户提交尝试，转只读查询，不再点发表、重传或新建相同投稿。不要补造点击时间；可分开记用户报告时间与平台显示时间。
2. **先查本账号管理页。** 按本期完整/规范化文案、时长、平台发布时间和实际作品 ID 绑定记录；有草稿 ID 时沿用。列表可能是旧数据，先有界等待。找到审核中记审核中，找到已发布记后台已发布；旧作品、成功 toast 或列表总数不能单独证明本片成功。
3. **记录不清楚时，再考虑刷新。** 优先刷新管理页重新查询；不要先刷新仍可能有未保存内容的编辑器。刷新编辑器前把当前文案、封面来源、设置及已知草稿 ID 留在项目，并确认能恢复；刷新后仍先查发表记录。无查重结果不等于确认未受理，保持结果待查，不自动重试最终提交。
4. **确认未受理才恢复同一稿。** 有明确拒绝/未受理证据且同一草稿可恢复时，保留原 attempt 和证据，按已有授权单步恢复。记录歧义或账号/ID不符时停止该平台；不要删账本、换 run-dir 或重开上传页来绕过去重。
5. **收敛操作。** 表单和弹窗串行，每次等后置状态；菜单出现、候选选中、画布变化、保存成功分别等。一次原入口恢复仍无响应时留一份局部诊断；新页只做同账号记录查询或恢复同 ID，不能再上传同片。不要因无回执反复用多套键鼠/注入方案点击相同按钮。

本次事实：用户手动发表后，视频号管理页出现本期完整文案和新发布时间；Agent 只回查，没有再次发表。网络波动、操作过密是可能原因，未取得网络日志证明；“刷新解决了”也没有经过本次对照验证，不能写成已定位根因或保证有效的修复。

## 富文本、提及和异步界面

- `@名字`纯文本不等于已通知本人。原生候选要用可核验的 ID、来源账号、头像等确认，不能仅按同名或粉丝最多选择；无法确认本人时保留文字引用并明确未关联。
- 富文本 DOM 刚改完并不代表框架已保存。原生选中提及后等实体节点出现，再追加后文；选择会异步重写文本时，过早追加可能丢失。失配后先读实际字段，不盲目追加。
- B站原生 mention 可能在实体两侧带 U+FEFF。仅在确认对应原生实体及 ID 后，正文比较可剔除这些不可见边界；不能放宽可见字符、用户规定首句或其他字段。这里是现场恢复经验，未声称通用适配器已实现。
- Shadow DOM 页面先定位实际控件；`focus()`、`Ctrl+A` 或设置 innerText 后，要核对表单和预览两处。内部框架 ownerDocument 尺寸可能为零，后台初始矩形可能异常；控件可见且布局稳定后再量坐标，滚动后重新量，不能用越界坐标连续试点。只有后台渲染确实受阻时按浏览器 skill 的最后手段处理焦点。

## 五平台各自读回

| 平台 | 现场检查与恢复重点 |
|---|---|
| 抖音 | 封面编辑初始页可能是竖屏，不能假设永远横屏。按当前比例分别上传3:4与4:3并保存，排除AI参考图 input。保存后“继续编辑”需等编辑器真正出现。管理页可刷新后按本期文案、00:53等实际时长和新时间核对，不能只拿发布成功 toast。 |
| B站 | 原生提及验证实体 ID；移除与本片无关的默认标签，分区/创作声明按实际素材选。创作声明下拉打开后要等候选出现再选；重开检查双封面、标签和正文。成功页“查看进度”进入管理页，取实际 BV 链接和本期时间。 |
| 小红书 | 同名 @候选不可猜。`published=true`只代表提交；管理页已发布筛选按本期标题、时长、时间和 DOM `data-impression.noteTarget.value.noteId`核对。脚本因同分钟证据不足保持黄灯时，可以补独立人工 UI 核验证据，但不伪造成功页回执 ID，也不把后台已发布说成外部所有访客可看。 |
| 快手 | 一次上传后等编辑页，封面切“上传封面”时 input 会变多，限定当前弹窗。比例文字可能和“推荐”混排，以实际节点与选中状态核验；确认后看主表单缩略图。作者声明、所有人可见与本片文案分别读回；待发布行可变为已发布，再取本条原生预览/数据页 ID，不重复投。 |
| 视频号 | Shadow input只负责选片；正文、短标题、封面保存和AI标注各自验证。短标题若不支持逗号，用空格等平台允许标点保留题意。检查默认位置，用户要求隐私时选择不显示位置；原创不自动勾选。保存/发表无回执遵循前述查询顺序；用户手动发表后保留现场、只查管理页本条新记录。 |

后台已发布、公开链接已取得、外部可访问、手机完整播放已验证是不同证据。每个平台分别报告本次账号、实际状态和待办，实际链接未取到就说明，不能凭空造 ID 或称全部外部播放已验证。

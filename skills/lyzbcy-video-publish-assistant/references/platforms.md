# 平台适配边界

| 平台 | 成功标志与关键差异 |
|---|---|
| 抖音 | 上传受理进入post/video；保存后重开回读。提交成功需本次点击已入账、manage路由及“发布成功”。横4:3与竖3:4分别验收；封面input排除replace和AI参考图，当前竖封面页脚与页签同名时用button语义。重开时段首星号只按已知序列化归一，不改正文内部星号 |
| B站 | 视频input在.bcc-upload-wrapper，不能选另一个buploader；标题/富文本使用实际DOM输入事件，避开滚动时点中隐藏mention节点。两个独立封面比率关闭同步，复用图片input时只清空该图片input。提交标志为本次点击后的“稿件投递成功”，不等于审核完成 |
| 小红书 | 等高清视频/处理就绪。悬浮主封面后进入“编辑封面”，上传3:4后明确选3:4裁切。暂存后等草稿列表真正出现再按唯一标题重开。发布按钮可能在shadow中，使用当前语义ref；success路由及“发布成功”证明提交，再按需看笔记管理终态 |
| YouTube | 常规视频16:9，Shorts优先9:16；图片预览真实改变后记账。保存会返回内容列表，等唯一ytcp-video-row及“编辑草稿”出现，不依赖旧a#video-title或固定延时。AI问句/儿童受众/语言/类别均回读；版权处理中黄灯。发布成功核对当前视频ID和带标题的发布时间对话框，排除背景旧行 |

## 小红书话题及终态

2026-11-20 实测：本地草稿重开后标题、正文和封面可以保留但视频为空。发布前额外回读本期文件名、视频可预览时长、高质量处理完成和发布按钮状态。只有现有稿件及审核列表都无本期、且原稿明确「暂未上传视频」时，才在同一原稿恢复媒体并保留旧账本。恢复后在当前就绪表单提交，避免重复暂存造成文件丢失；审核中由唯一标题、时长、发布时间与原生笔记 ID 回读。

同名话题按当前候选 DOM 的 `data-impression.tagTarget.value.tagId` 填 `topic_ids`。无唯一候选时停下消歧，已有实体和半成品保留以防重复。提交成功页 `published=true` 只记受理。用 `confirm_published` 在已发布筛选按标题、时长、时间和 noteId 核验。普通直链打不开时可用后台作品卡验证，分别记录可播放与站外访问。

## B站活动标签

普通标签与活动参与是两条通路。`topics`是普通候选；`activity_topics`显式指定至多一个活动。普通候选返回“当前tag为话题专用/不允许自定义添加”等新提示时，进入“搜索更多话题 >”，精确搜索并选中一个活动；结果点击后须实际选中并回读，不以搜索命中当参加成功。旧toast先消失再验证下一标签，避免串判。

超出一个的候选写入omitted，不暗中换成无关热门活动。活动搜索/确认控件变化即红灯；这一通路已编码及离线测试，尚未在真实活动选择器完成端到端回归，不宣称已全自动实测通过。

## 声明与媒体要求

原创声明不等于 AI 内容声明。成片或图文含合成配音、生成图片或画面、合成动效时，默认如实设置 AI 生成声明，视频与图文两条投稿各设各的，保存重开后回读；作者要求不声明时按 SKILL.md 的流程处理。缺控件时记录「当前入口未提供该控件」及所查页面。已经发表的作品优先在原稿修改，不删除重发；抖音和小红书实测可补；公众号 2026-11-25 实测的修改入口没有该控件，按发表前设置处理。

本次已采用的字幕、显示词表及音源限制随母版交接。音源使用条件或版权检查与原创、AI 声明分别核验。

## 合集/播放列表：独立于作品发布

当前四平台可通过已登录UI创建并关联合集/播放列表；此路径是人工浏览器实测，尚未接入CLI自动创建，不宣称一键支持。先搜索并核对现有同名合集，复用本次创建记录；创建尝试先入账，不因超时或列表暂时为空重复创建。用户只授权准备时，不为入集自行发布作品。

| 平台 | 本次观察到的路径与验收 |
| --- | --- |
| 抖音 | 空合集可能处于待发布，投稿下拉框未列出。若本次已授权且视频已发布，可进入该合集编辑页添加目标作品并保存。保存后核对作品数与唯一标题；合集可能另行审核，公开按钮禁用时保留待办，不重建或重发 |
| B站 | 投稿页创建并加入后，保存重开核对合集名；投稿成功页“已加入合集”证明关联，不替代视频发布终态检查 |
| 小红书 | 原生“创建并加入”后核对预览合集名，再保存重开；预览中的篇数不是匿名访问证明 |
| YouTube | 新建公开播放列表后核对勾选、完成、保存重开；内容列表中核对播放列表名、公开范围和视频数，视频本身仍按绑定ID核验公开状态 |

合集名称、创建尝试、UI观察到的ID、关联本期、保存重开、审核/公开状态分别留项目记录。回执可以是“视频已发布，合集审核中”；不能把视频发布成功当作合集已公开。现有授权/指纹、防重、用户接管规则继续有效。

### YouTube隐藏编辑器与无链接草稿

播放列表创建窗口关闭后，其contenteditable可能仍留在DOM，且与视频字段共享aria-required。默认配置按上传窗口内实际视频aria-label限定字段；读取前检查可见上传窗口和字段唯一性，缺失/歧义就停止，不清除隐藏DOM或退回第一个全局字段。界面语言或标签变化时按当前UI配置，不猜字段。

重开草稿行可能没有视频链接。唯一可见标题和“编辑草稿”只允许打开查看；若行内存在视频ID，必须与已绑定ID一致。打开后再次核对绑定ID，缺失/不符即停止，绝不继续填表或发布。

### 固定已验证控件，减少反复试探

普通B站标签使用当前唯一输入框的可信键入并回读，成功关联后跳过；不将该输入策略全局推广到所有富文本。抖音封面的 `covers` 脚本按初始为横版写：固定先传 4:3，再点「设置竖封面」传 3:4，不读当前比例。2026-11-24 实测编辑器改版后初始是竖版，`covers` 找「设置竖封面」按钮得到 0 个，会转红灯，改按[运行手册](multiplatform-runbook.md#2026-11-24-实测补充抖音视频)的人工步骤。页面标题换行不影响就绪判定。小红书封面输入按当前原生image upload-input定位。控件缺失或歧义仍停止，保留一次局部诊断，不能靠第一项猜测。现场手动方案曾实际成功；这些固化实现有离线回归，未重复真实投稿验证新版全链。

### 多平台成片平台中性规范（2026-11-26）
同一母版面向多平台时，原则上不在画面、字幕、旁白、转场、片尾、截图和封面中露出其他分发平台的名称、Logo、站内口令或可识别链接；确有必要作为本期分析对象时另按用户要求处理。跨平台作品数据可以使用真实来源，但画面呈现改为「热门作品精选」等中性名称，只展示真实可核的指标，不凭空变更指标或假称其他来源。原始来源证据留项目私有文档。出片前检查最终画面及字幕/旁白文字，作者要求平台专属版时单独派生，不将平台专属字样烧入通用母版。

### B站图文备用通路
动态图片选择器不能稳定附加真实图片时，不发空稿；从创作中心进入官方专栏投稿，以最终成片来源的同一批已审图文发九图流专栏（实际管理页归类为图文），独立记录 `delivery_form=column_image`、公开 `opus` ID 和专栏回执；收到该图文回执后不用再发同一动态。先确认当前专栏编辑器支持文件拖入；在图文尾段逐图拖入，逐张核对本地 data URL SHA，保存重开确认九张已加载的远程图片、AI声明和批准封面。话题可能重开丢失，按实际 UI 重新选入。详见 `extension-scripts.md`。

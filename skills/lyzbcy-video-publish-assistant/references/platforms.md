# 平台实测记录（2026-10）

页面文字和工具能力可能更新；以下只作为定位线索。示例不包含账号、Cookie、作品私有数据或固定元素编号。

## 抖音

入口：`https://creator.douyin.com/creator-micro/content/upload`。上传后通常进入 `/content/post/video`。

1. 通过当前工具的文件选择器上传，等编辑页加载。标题曾出现 placeholder `填写作品标题，为作品获得更多流量`，正文是 contenteditable 富文本。可见标题不超过30字。
2. `横封面4:3` 与 `竖封面3:4` 分别进入编辑器。上传对应图片，再检查对应预览，完成后主页面应出现两张封面与检测结果。横图自动同步到竖封面时仍应替换为独立竖版；不能默认裁切没问题。
3. 话题输入井号和关键词，等待准确候选再选中；已关联的话题在编辑器中呈实体样式。一次选一个，避免一次粘贴全部后误以为已关联。
4. `自主声明` 按实际内容选择。确认其他平台同步保持用户选择，页面初加载与稳定加载的控件可能不同，不在骨架屏状态修改。
5. 需要保留待发布时用 `暂存离开`，随后上传入口可能出现“你还有上次未发布的视频，是否继续编辑？”。点 `继续编辑` 回读标题、正文、话题、双封面和声明，停在编辑页。最后的 `发布` 只按本次授权处理。

实测陷阱：富文本 fill 曾追加旧正文；文本框全选清空后由工具支持的剪贴板粘贴可正确替换。长文本逐字输入曾在中途超时。完成后逐行检查一次，不能只看字符数。

## B站

入口：`https://member.bilibili.com/platform/upload/video/frame`。

1. 当前可见的“点击上传或将视频拖拽到此区域 上传视频”能唤起文件选择器。页面可能有多个文件input，点击隐藏或不活跃的input曾无法获得选择器；先使用可见上传区域。
2. 上传完成后回读标题，曾被自动改回文件名。标题曾显示80字上限、placeholder `请输入稿件标题`。如果fill之后失焦回退，可改用工具提供的真实键盘输入或粘贴，回读到正确值再继续。
3. 分区应按视频内容选，如健身；不要保留错误自动推荐。删除不适合的自动标签，再逐项添加，等待每项校验完成。曾一次快速添加五项但实际只保存一项。
4. 封面编辑器有 `首页推荐封面（4:3）` 与 `个人空间封面（16:9）` 两个独立画面。先上传4:3，切到16:9再上传16:9，检查“双比例同步改动”状态，防止第二次覆盖第一张。两张都看过再点封面编辑器的 `完成`。若第二张与前图文件选择无变化，确认当前是图片input后可清空该图片input再选图；绝不清空视频input来重试封面。
5. 按实际选择 `创作声明`，例如 `含AI生成内容`。正文编辑器与动态描述是两个不同字段，别把正文填进隐藏剪贴板节点或动态字段。
6. `存草稿` 成功会到草稿列表。打开刚保存的标题回读，通常含 `type=draft&draftId=...`；确认上传完成、封面、标题、分区、标签和简介仍在。`立即投稿` 会提交，用户要自己确认时停在此按钮之前。

## 小红书

入口：`https://creator.xiaohongshu.com/publish/publish`。

1. 上传视频，等当前文件名与高清视频提示稳定；标题曾是 `填写标题会有更多赞哦`，20字上限；正文为 `.tiptap.ProseMirror` 富文本，限制以现场为准。
2. “设置封面”可能只是区块标题。实际入口是当前封面缩略图悬浮后出现的 `编辑封面`。切去其他标签会让悬浮按钮消失；必要时在同一目标页完成悬浮/点击，按当前截图定位。
3. 编辑器 `上传封面图片` 选择独立3:4图片。随后到 `裁剪` 选 `3:4`，看完整标题、脸、副标题，再点编辑器 `完成`。实测仅上传3:4图，预览仍可能按旧横版裁切；“封面评估通过”不能证明构图正确。最后到 `封面预览` 检查真实信息流展示。
4. 话题逐项关联；选中后页面会表现为话题实体，回读文字可能带 `[话题]#`。建议列表加载或切后台后消失时先恢复输入焦点，不盲点旧候选。
5. `添加内容类型声明` 中有 `笔记含AI合成内容` 等选项，按实际制作情况填。原创、地点、群聊、活动、投票、小工具等可选项不要为了“填满”添加无关内容。
6. 待用户确认时使用 `暂存离开` 并从草稿箱重新打开回读。出现 `published=true` 只是核对线索；去笔记管理按标题与时长确认是审核中、已发布还是别的稿件，避免创建第二份投稿。不要把提交审核说成审核通过。

## YouTube

脚本已封装的现场分支位于`scripts/youtube.py`：上传页暴露的Shorts链接/竖版控件决定封面比例；高级设置按可访问名“显示高级设置”定位，避免视觉文字“展开”附近的验证链接；保存实际视频ID和已观察编辑链接；重开时查对应Shorts/普通视频列表。标题节点不一定有href，可按当前唯一匹配稿件行的“编辑草稿”按钮重开；不拼猜链接。类别定位`ytcp-form-select#category`，等待语言/类别真实选中值。版权步骤返回实际文字，后台处理未完成时保留pending断点。遇到`/video/<id>/edit`普通详情页，先核对用户是否已提交，不当成原草稿继续填写。

入口`https://studio.youtube.com`。2026-10-17实测上传后自动保存私享，关闭上传窗口并从频道内容重新打开核对；不把自动保存说成公开发布。

1. 视频input为`input[name=Filedata]`；编辑器标题/说明为两个`[contenteditable=true]`，可通过`aria-required=true/false`区分。标题100、说明5000字，以当前页面为准。
2. 缩略图input为`input#file-loader[type=file]`。常规视频使用16:9，实际为Shorts时用9:16；只有3:4海报可由已有FFmpeg补边。横封面在Shorts页面会被居中裁切，不能因为上传成功就验收。检查实际缩略图预览，不能只看本地文件。账号如需要验证才能自定义缩略图，保留草稿并报告此限制。
3. 标签初始placeholder为“添加标签”，添加后placeholder可能清空；`input[aria-label=标签]`更稳定。逐项Enter并读回标签chips。
4. “展开”显示受众、AI使用情况、付费宣传、语言和类别。按当前问题和真实内容填写，不把卡通等同儿童向，不把AI动画说明等同任何平台的逼真修改问句。不要开启无关商业/同步选项。
5. 语言下拉有很长的菜单，多层元素重复相同文字；定位实际选项后scrollIntoView再可信点击。类别按内容选择，如音乐。等待实际选中值，不仅等待菜单出现目标字样。
6. 上传窗口关闭按钮在本次界面为`ytcp-icon-button.close-button[aria-label=关闭]`；其他版本可能为“保存并关闭”。关闭前等待“已保存为私享视频”，然后从频道内容对应标题重新打开。
7. “检查”里版权主张与版权警示不同；记录当前覆盖面/创收影响。不要自动争议、静音或替换用户确认的歌曲。

## 预检 Manifest

路径相对 manifest 所在目录解析，也可用绝对路径。平台键仅列本次目标；封面键列本次具备的比例。

```json
{
  "video": "final.mp4",
  "covers": {"4:3": "cover-4x3.jpg", "3:4": "cover-3x4.jpg", "16:9": "cover-16x9.jpg"},
  "platforms": {
    "douyin": {"title": "作品标题", "description": "正文", "topics": ["话题"]},
    "bilibili": {"title": "作品标题", "description": "简介", "topics": ["标签"]},
    "xiaohongshu": {"title": "作品标题", "description": "正文", "topics": ["话题"]}
  },
  "mode": "prepare"
}
```

本地路径、具体稿件标题、平台账号与最终状态报告保存在用户项目内；公开skill包不收录这些运行时资料。正式发布授权应来自当前用户，manifest中的mode不能扩大授权。

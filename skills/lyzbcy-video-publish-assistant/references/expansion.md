# 扩展平台与发布策略

完整 CLI 对应抖音、B站、小红书、YouTube。以下仅在用户本次选择扩展平台时读取。具体可运行步骤见[扩展脚本](extension-scripts.md)，多平台组合见[运行手册](multiplatform-runbook.md)。

- **X、快手、微博**按本次授权和实际界面处理原生视频。X 有独立步骤，快手和微博仍需现场 UI。平台限制以当前账号为准，必要时派生文件并保留母版。
- **微信视频号**的授权绑定本条成片、封面和文案。明确授权的多条可分别登记。网页缺少好友可见范围控件时如实报告。
- **公众号**仅发表与群发分开。公众号群发默认关闭，本次群发授权不扩展到其他文章。“默认关闭”指本 skill 的约定；2026-11-23 实测发表弹窗的开关默认是开启，每次先读回再点发表。较新的明确授权覆盖同一篇旧约定，并绑定账号、正文、封面及引用动态。
- **公众号、知乎、掘金**可共用同一正文源，按各平台适配排版。公众号与视频号同发时，先核验视频号成片的唯一动态标识，从公众号「视频号」入口引用该条，禁止公众号另走「本地上传」。视频号未就绪则文章保持草稿。外链只可作为明确的替代方式。

## X 草稿无法恢复

先有界尝试重开，失败记录一次局部诊断。只有已核对账号主页无对应发布、旧稿已明确停止且仍具授权时，才在干净编辑器重建一次。视频 Ready、正文、AI 声明均回读后单次提交。用原生帖子 ID 与公开正文核验，HTTP 成功或编辑器关闭只作为查询线索。

## 合集、活动与可见性

当本次用户要求系列运营时，发布前回读各平台实际合集名称，选择对应合集并核对保存重开结果；缺少合集且已授权本期加入系列时，按该系列采用名称创建并再选中。记录本条关联状态。

活动以本次账号投稿页的候选与活动详情为依据，核对有效期、内容方向、必带话题及关联账号。选择与视频内容吻合的活动并回读已选；没有符合项时记录检索范围和结果。B站仍遵守每条至多一个活动话题。

用户要求声明原创时，依据本片实际创作、素材使用确认及平台条件设置原创选项，回读其状态；AI生成标识与原创声明各自核对，不能相互代替。记录平台不支持、资格限制或冲突的具体依据，不把用户授权写成独立版权核验结论。

用户明确选择“视频号＋公众号”矩阵时，先核对本期视频号成片、标题、独立封面、合集、活动和声明，确认提交及视频身份，再在公众号正文嵌入对应视频号视频，重开核对关联身份和预览；与单独上传公众号视频素材区分。按本次用户意图保留图文阅读内容，公众号群发另按授权。

朋友可见性要求作为本次发布条件记录，以当前平台实际控件和用户确认核对；用户后续明确调整条件时保留原要求及最新指示，再按新范围执行。不能把未设置的标签屏蔽写成已生效。普通网页缺少微信好友标签入口时如实记录，需要手机侧设置则说明具体缺口。


## 人工扩展步骤

视频号已人工完成原生上传、专用双比例封面、创建并选中合集、勾选原创、AI标识及提交，结果为原创审核中；这不等于已接入CLI。保存草稿后重开，声明项可能恢复默认，正式提交前须在同一次表单中再次回读。活动入口无候选时只记录本次入口检查结果，不宣称遍历所有官方活动。

视频号封面“编辑”可能先打开“直接编辑/使用素材”选择，进入实际裁切框后才选入文件。确认裁切后等待主表单缩略图改变或“封面已更新”，再保存并重开，不能把文件已选入当封面已保存。合集补发旧期后可能按添加时间排在新期后；使用“更改排序”的真实拖动，把具体期号排好并保存、重开核验。小红书合集预览的“共N篇”可能含缓存或当前稿，必须逐篇回读原笔记的关联，不能只凭总数判齐。

公众号引用视频号、发表验证及恢复操作见[运行手册](multiplatform-runbook.md#公众号扫码审核和窗口恢复)。

知乎已人工完成原生讲解视频上传、视频标题及封面、文章封面、话题、AI辅助创作声明与发布。AI创作声明在草稿重开后曾恢复无声明，须提交前复核并在发表页回读最终声明。

掘金本次账号的Markdown预览过滤普通iframe，Markdown与富文本工具栏均未发现原生视频插入入口；正文可保存草稿，不能据此宣称视频已嵌入或文章已发布。若用户要求嵌入视频，封面加播放链接属于需要明确说明的替代方案。

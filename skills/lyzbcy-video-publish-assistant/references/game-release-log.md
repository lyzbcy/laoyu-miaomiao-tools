# 游戏集锦发布：合集、声明与限时日志

用户指定游戏名、合集、平台范围、原创声明、活动或投稿时限时使用。以下为已实测的操作经验，页面变化时以当前界面为准；不新增平台授权，不承诺七平台一键完成或固定十分钟完成。

## 开工与时限

1. 记录已采用成片的绝对路径、SHA256、时长，以及封面、文案和用户本次授权。游戏名、合集名取用户原文，不按识别结果猜，不成为其他系列默认值。
2. 尽早核对本次所选平台的登录与账号。需要扫码时立即交给用户，继续其他可执行平台；不等到最后一个平台才发现缺登录。
3. 优先复用已核验素材和适配器；单个浏览器session的表单操作串行，已受理上传可在后台自然处理。活动搜索设时间预算，只参加规则和资格明确匹配本片的活动；未核实或无合适项就记录略过，不挂其他游戏/购物/摄影活动。
4. 截止前先给当前状态：已发布、已提交待审核、上传中、阻断分别列出；超时说明实际耗时与有据可查的原因。正常流程避免重扫整页；异常只读相关控件。时限不是减少稿件核验或重复点击的理由。

## 项目私有日志

在同一run目录保留 `publication-log.json`（当前状态）、`events.jsonl`（追加动作）与 `run-summary.md`（结果、证据和续跑）。账号、稿件ID、tabId和真实DOM只进项目，不进入公开skill。

当前状态至少记录：run_id、开始/目标截止/实际结束、视频指纹、平台与账号、采用文案/封面、上传及提交尝试、状态、原生ID/链接、证据路径、声明/合集/活动和下一步。动作事件可用下面的结构；实际记录时替换示例值：

```json
{"run_id":"example","platform":"platform-name","action":"submit","attempt_id":"submit-1","phase":"start","at":"2026-01-01T10:00:00+08:00","video_sha256":"example-fingerprint"}
{"run_id":"example","platform":"platform-name","action":"submit","attempt_id":"submit-1","phase":"end","at":"2026-01-01T10:00:03+08:00","elapsed_ms":3000,"result":"submitted","evidence_path":"local-evidence.txt"}
```

上传、最终提交、合集创建在外部动作前写start/attempt，完成后写结果。中断留下未完成attempt，续跑先查询对应稿件；结果不明不得重新提交。恢复确需重传时，记录原稿未提交/已废弃的证据、新attempt与原因。早期缺起止时间就写未知，不能用读日志的时间补造旧动作耗时。

用现有恢复脚本判断下一步；本页日志示例不是新增自动编排器。已发布平台跳过，不因补发另一平台重新投一遍。用户接管修改的稿件按原门禁保持只读。

## 三组状态分别核验

| 对象 | 分开记录 | 不能混同 |
|---|---|---|
| 视频 | 上传受理、提交、审核中、平台内已发布、外部公开 | 有管理行或原创审核状态，不证明视频已公开 |
| 合集 | 创建、选中本片、保存关联、审核/公开 | 创建成功不证明本集已加入 |
| 声明 | 原创申请/结果、自制授权、AI标识、许可 | AI标识或简介“本人录制”不证明原创申请受理 |

原创、音源和AI条件沿用[平台约定](platforms.md)与[声明要求](../SKILL.md#原创声明视频号复用与群发)。当前入口未提供独立控件时记所查页面和限制，不推广为整个平台永无该功能。需要保存重开时按已有路径核验；未验证的步骤明确留待办。

## 平台易错点

- **B站**：投稿页可新建并加入合集；AI创作声明与自制授权分别核验。按当前新稿标题、时长、发布时间和真实BV链接确认终态。
- **小红书**：原创开关会打开须知，需同意并确认“声明原创”后回读；只点文字不算开启。合集“创建并加入”与AI合成标识分别核验；发布后在笔记管理已发布筛选中用标题、时长、时间与DOM noteId绑定当前稿件。
- **YouTube**：新建播放列表有多层菜单，每次点击等待目标状态，不在旧菜单未更新时反复点下拉。核对指定列表，只纠正本次误选；私享保存不等于公开。标准许可不等于独立原创申请。
- **快手**：内容管理→合集管理新建，添加列表的实际加号选本片，不点标题代替；保存后核同名合集及包含的视频。当前发布器缺原创控件时只记录当前入口限制。
- **抖音**：作品封面、合集封面分开保存；发布后可在作品合集新建并用加号加入本片。视频已发布、合集审核中与合集公开设置分别记账，审核中只查询。
- **X**：通用富文本替换已有多行/话题曾产生重复，不能只凭工具成功发稿。正文回读不符先停；确认未提交后，可丢弃本次自建错误草稿，在全新且已核为空的编辑器可信插入一次，按记录受控重传。Ready、正文与账号一致才单次提交，再核原生帖子及视频时长；该恢复路径不适用于提交结果不明的稿件。
- **视频号**：短标题符号按实际校验提示处理，游戏名仍保留正文。Shadow DOM自定义textbox包装层fill失败时，定位已观察的实际input/编辑器，核空值后聚焦并可信插入，回读value/innerText。

## 视频号关联与封面

合集创建后菜单可能暂未刷新，等准确名称出现再选；总列表短时计数0不能断言关联失败，进入详情核数量与本片正文。详情“视频审核中”与列表“原创审核中”分别记，不能报告已公开。

封面进入对应卡片的实际编辑器，素材提示层按需要选“直接编辑”。3:4和4:3各自上传，等Preview实际图片/尺寸变化再确认；只选入文件或过早确认可能保存上一张图。确认后等上传完成并重开核对；未完成最终持久化回读时如实留待办，不编造尺寸或成功结论。

本页来自一次六平台确认发布、视频号登录后补交并待审核的实操。该轮未达十分钟，早期动作时间不完整；这些结果支持上述恢复和核验方法，不构成提速已验证、全链CLI或固定耗时保证。

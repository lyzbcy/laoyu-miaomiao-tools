# 现场讲稿、互动与交付

## 现场流程

1. 把原话按页分段。翻页、点击、交话筒、演示、冷场提示放在方括号。变化只改相应段落并同步 PPT。
2. 双讲者提前确认分工与交接，尽量在前一天彩排。确认演示账号、权限、输入、可核验输出与目标放映机器。断网或工具卡住时展示已备好的产物。
3. 主流程和问答、抽奖、交流、离场的时长加总应与活动总时间匹配；另备压缩版，保留主旨和关键互动。
4. 有推广目标时，提前说明资料或继续答疑的获取方式，预留扫码时间；同学自主参与，活动规则提前与组织方确认。报名、到场、抽奖、加好友和签到签退分别统计。

## 手机阅读图

- 时间一图流采用窄单栏，参考画布 720 CSS px，正文 40–44 px（390 px 手机宽显示约 22–24 px）。时间用清晰数字字体，呈现开始时间、讲者、页码和台上动作。
- 完整讲稿保持原话。点击提示、交接、关键时间、转折及扫码提示浅黄底高亮。避免整段标黄，短词组不在中间折行，长词组可合理换行。
- 以手机实际宽度核对首段、转场、结束、救场。如果长图被客户端压缩，可另做分段 PNG 或 PDF。

## 协作和结项

- 协作文档先获取最新版并备份，确认不存在其他新修改；在原链接同步后读回页数、备注或可比哈希。
- 标准二维码用原图或保留留白的截图裁切，原码与投屏图进行解码比对。小程序码等特殊码使用原图，实际客户端试扫验证。
- 活动后保留最后制备稿及实际发放的手机稿，归档历史版本。复盘分别记录计划、真实反馈、未确认数据及下次优化。

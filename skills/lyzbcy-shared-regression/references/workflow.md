# 使用与维护

## 三项核心能力的接入与验收

### 精准设计映射

用例ID → 实际PC/H5入口 → 页面/弹窗/状态 → 对应画板。先检查已有映射和明确确认稿，必要时查看真实画板内容，不凭文件名或整个章节猜图。一个用例涉及多态时可切图，并说明核对位置；切换用例及入口后同步引用。图片加载成功只证明资源存在，不证明选图准确。缺稿或仅有历史参考要在界面说明。

### PRD独立窗口、强制置顶与原文蓝选

独立窗口与对照台并排使用，切换用例复用原窗口并更新定位。系统级置顶需本机窗口适配器支持，并确认目标是PRD窗口；提供取消置顶，失败明确提示。浏览器网页的z-index、window.focus和新标签页均不等于系统级置顶。不同系统单独适配，缺能力不伪报成功。

定位以原版PRD已登录会话为基础，按章节及准确短句找到正文，唯一命中后用文档原生选区蓝选，并核对实际选区内容。不能蓝选标题/目录冒充正文，不能改文档内容或背景样式冒充选区。登录过期、连接断开、多命中、短句缺失时保留明确错误及重试入口。浏览器与本机适配器按现有项目机制调用，不打包用户会话或公司文档。

验收至少覆盖独立窗口打开/复用、置顶/取消、切用例定位不同正文，以及连接失败时的反馈；不能只验证按钮出现。

### 辅助演示

将选中用例步骤映射为实际页面动作，区分逐步与自动执行；演示面板说明当前步骤、前置、完成或阻塞原因。已有适配器优先复用，操作真实可见控件；受控响应或临时状态需明确标识。停止、异常和结束均恢复本次临时状态，已有用户草稿不覆盖。保存、发送、删数据等按本次授权执行，不因点击演示就隐含获准。

验收实际执行代表流程、停止/失败后的恢复及切换用例，未适配项显示不可执行原因。演示完成与业务断言结果分别呈现，不能自动记为回归通过。HTTP检查不代替页面演示。

## 数据与运行

`init` 将模板写到指定项目目录；`cases.json` 是当前定义，`regression.sqlite3` 是本机历史，`index.html` 是对照页。更新 skill 不改项目文件。模板页面后续更新应先比较差异，不覆盖使用者改动。

0.1.3 模板可在用例中配置以下字段；创建批次时冻结，修改后需创建新批次：

```json
{
  "entries": [{"id":"pc", "label":"PC", "url":"http://127.0.0.1:8000/"}],
  "references": [
    {"type":"image", "label":"编辑状态", "entry":"pc", "state":"编辑", "url":"http://127.0.0.1:8000/design.png", "source":"设计稿", "version":"v1"},
    {"type":"prd", "label":"原文", "url":"http://127.0.0.1:8000/prd", "quote":"唯一的原文短句"}
  ],
  "demo": [{"action":"highlight", "selector":"#field", "label":"观察字段"}]
}
```

引用不写 entry/state 表示通用于当前用例；配置项不匹配时显示无资料。PRD 选择要求独立窗口可同源读取，短句须完整存在于单个文本节点且唯一，跨域和复杂编辑器需要项目适配。演示支持 highlight、input（附 value）和 click；仅同源 iframe 可访问。停止会还原高亮和输入，不撤销点击引发的状态或后台操作，必须仅配置已授权的安全动作。设计图预载有开关，最多三张，不能代替业务页预载。系统置顶、跨域适配、业务页预载和自动恢复服务尚未实现。

项目目录 `public/` 中的 HTML 和图片可用 `http://127.0.0.1:<端口>/public/<文件名>` 访问；只放允许本机浏览器读取的资料。对真实跨域业务系统，不应为了同源演示绕过其登录或安全策略。

```json
[
  {
    "id": "DEMO-001", "title": "表单取消恢复", "url": "http://127.0.0.1:8000/form",
    "prerequisite": "使用专门测试样本", "steps": "打开表单，修改草稿，取消后重新进入",
    "references": [{"label": "PRD 对应段落", "url": "https://example.com/prd", "note": "章节及版本"}],
    "checkpoints": [{"id": "cancel", "title": "取消后显示原值", "mode": "human"}]
  }
]
```

引用可放PRD、设计图或历史原界面URL，均由用户配置；页面默认使用第一个引用，可切换打开原文。推荐资料服务提供 HTTP URL；本地文件路径不会自动变成浏览器可访问资源。无法内嵌、需登录或CSP禁止时使用“独立打开”。

自动检查点使用 `mode: "auto"` 及 `http: {"url": "http://127.0.0.1:8000/health", "status": 200, "contains": "ok"}`。url必须明确配置，contains可省略；执行器只做GET，不注入凭据、不跟随重定向、不重试写操作。确认目标GET不产生业务副作用。网络错误记blocked，明确断言不符记failed；正文最多读取1MiB。检查使用当批次冻结配置。只选自动检查点存在的用例，未适配检查点保留pending。

AI浏览器复核后可追加真实身份记录：

```text
python <skill>/scripts/qa.py --project <项目目录> record 批次ID --case DEMO-001 --point cancel --actor ai --name AI代理复核 --status passed --note 实际观察及证据位置
```

网页只填写人工或AI代理身份，自动记录由执行器生成。证据路径作为文字说明保存；当前版本不上传/托管证据文件。summary默认只返回统计与用例状态，`--case` 才展开单条历史。整个项目目录按私有测试数据保管。

## 资料映射和人工接管

- 先按用例核对真实入口、预期与引用顺序。员工范围、任务弹窗等用例不要统一默认到整页列表；一个画板含多态时说明具体位置。
- 保留来源、版本、归档日和适用范围。历史图不称最新稿，运行截图不冒充设计稿；删减功能对照使用真实旧图并保留来源。
- 解释“怎么测”要写清入口、样本、动作、预期与缺口。通知跳转需要通知URL，普通详情入口不能代替；取消协作身份不必然失去管理员等其他权限。
- 数据契约类用例按请求与回读核对，不虚构设计画板；PRD目录定位不等于正文选区确认。
- 已有平台从原数据按ID读取，保留原localStorage/数据库和历史证据；变更映射后实际切换受影响用例验证。脚本更新核对HTTP实际内容与缓存，单凭文件已改不代表浏览器已生效。
- 登录成功不代表环境、角色或特性版本正确；分别核真实页面、身份、加载模块和请求上下文。前后端版本大小写按项目配置，不写死某次环境。

## 扩展与边界

首版是单机使用的轻量模板。人工和AI共用定义/批次/记录，脚本不调用模型。浏览器自动化需要按具体项目补定位和断言，复用现有工具；不把演示动作列表当自动覆盖清单。真保存、删数据、改权限、发送通知等依本次授权与测试样本执行，不因启动回归台而隐含获准。

需要多人跨机器时另设计认证、权限和服务部署，不直接把回环服务暴露公网。脚本serve可与只读summary并行，但同一个项目的自动run应串行执行。当前不提供团队托管或并行浏览器执行器。

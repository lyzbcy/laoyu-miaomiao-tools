# lyzbcy-video-planner

短视频方案管理技能。管理 `E:\短视频创作\编导` 目录下的方案文件。

## 触发条件

- 用户提到"方案"、"编导"、"短视频计划"
- 用户说"创建新方案"、"查方案"、"方案列表"
- 用户用编号引用方案（如"查01"、"更新02状态"）

## 命令

### 查看方案列表

```
/list
```

列出所有方案，显示编号、名称、状态。

### 查询方案

```
/get <编号或关键词>
```

示例：`/get 01` 或 `/get 星星布丁`

### 创建新方案

```
/new <方案名称>
```

自动分配下一个编号，创建模板文件。

### 更新状态

```
/status <编号> <状态>
```

状态：`进行中`、`待拍摄`、`已发布`、`废弃`

## 文件命名规范

```
<编号>-<方案名称>[-<状态>].md
```

示例：
- `01-AI一键搞定实验报告-已发布.md`
- `02-星星布丁机器人.md`（进行中，省略状态）
- `03-xxx-废弃.md`

## 状态说明

| 状态 | 文件名后缀 | 说明 |
|------|-----------|------|
| 进行中 | 无 | 默认状态，省略后缀 |
| 待拍摄 | `-待拍摄` | 方案完成，等待拍摄 |
| 已发布 | `-已发布` | 已发布到平台 |
| 废弃 | `-废弃` | 不再推进 |

## 方案审核原则

每次创建或更新方案时，必须审核以下几点：

### 1. 利他性（核心）
- 内容是否对观众有价值？
- 观众看完能得到什么？
- ❌ 自嗨型内容（只展示我很牛）
- ✅ 利他型内容（观众也能做到/学到）

### 2. 开头抓人
- 前3秒决定留存率
- 目标：3秒留存率 ≥ 50%

#### 有效开头模式

**① 猎奇形容词开场（强烈推荐）**
先用猎奇词+神秘感开场，勾住好奇心，再揭晓真相：

| 开场钩子 | 揭晓真相 |
|---------|---------|
| "给你们分享一个巨恶心的东西" | "恶心的是，以前我居然傻傻手动做..." |
| "今天我们来挑战一个特别刺激的" | "刺激在哪儿？一次性搞定一周工作量" |
| "这个方法真的太变态了" | "变态到什么程度？点一下就全完了" |
| "我要报警了，真的要报警" | "AI帮我写完了作业，这算不算作弊？" |
| "这玩意儿离谱到我想吐" | "离谱的是，我以前居然不知道" |
| "分享一个让我发疯的东西" | "发疯是因为...太省时间了" |

**万能公式：**
```
"给你们分享一个巨[猎奇词]的..."
"今天我们来挑战一个特别[猎奇词]的..."
```

**常用猎奇词：** 恶心/刺激/变态/离谱/发疯/想吐/报警/可怕

**关键：** 前半句要够夸张够神秘，后半句要能圆回来，形成"原来是这样"的反差感

**② 反差开场**
- "虽然我只有100粉丝，但是..."
- "零基础，做出了这个..."

**③ 痛点开场**
- "每次写实验报告都要..."
- "这个痛点困扰了我三年..."

**④ 好奇开场**
- "我给我的女朋友做了一个..."
- "偷偷用AI干了这件事..."

#### ❌ 避免的平淡开头
- "大家好，我是xxx"
- "今天给大家分享..."
- "这个视频教大家..."

### 3. 节奏控制
- 每5秒一个小爆点（情绪/信息/画面变化）
- 保证完播率
- 爆点类型：
  - 情绪波动（搞笑/惊讶/感动）
  - 信息输出（干货/技巧）
  - 画面切换（特写/转场）

### 审核清单

创建/更新方案时，检查：

```
[ ] 利他性：观众能得到什么价值？
[ ] 开头：3秒内能否抓住观众？
[ ] 节奏：是否有5秒一爆点的规划？
[ ] 热点结合：是否蹭到近期热点？
```

## 热点追踪

**定时任务：** 每天10:00 检查领域热点

### 热点来源
1. **抖音热榜** — 查看AI/学习/恋爱相关热点
2. **B站热门** — 科技区/学习区/情感区
3. **小红书热门** — AI工具/恋爱技巧/学习效率
4. **微博热搜** — AI相关话题
5. **跨领域出圈内容** — 二次元鬼畜/爆款BGM/梗

### 热点筛选标准
- 与目标用户相关（AI+恋爱/学习）
- 或出圈内容可改编使用
- 有时效性，能快速产出内容

### 输出格式
每天10点推送热点简报：

```
📅 今日热点简报 <日期>

🔥 AI圈
- xxx新模型发布 → 可做对比测评
- xxx玩法爆火 → 可出教程

💕 恋爱方向
- xxx话题热议 → 可蹭

📚 学习方向
- xxx痛点爆火 → 可做解决方案

🎬 跨领域出圈
- xxx鬼畜/梗 → 可改编使用

建议选题：
1. ...
2. ...
```

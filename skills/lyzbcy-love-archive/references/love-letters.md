# 情书与表达 · 四个原则

> 来源：一个长期情书工程（100 封目标）的风格归纳，脱敏为通用方法论。

## 表达的四个原则

1. **反复确认式**——给对方随时验证的安全感：
   「你可以永远一次一次向我确认，我也会完全真心实意」。
   不要嫌"又问一遍爱不爱"，把回答当成日常功课而不是负担。

2. **诚实不夸大**——不滥用"永远"：
   「也可能不是那么永远，但我现在足够足够爱你，所以才能说出这句话」。
   有限的诚实比无限的大话更动人，也更经得起吵架时回看。

3. **行动化承诺**——不说空话，承诺具体的事：
   「让你少辛苦」「给你摆水果捏肩膀」「给你做小饼干」。
   检验标准：这句话能不能在下周兑现？

4. **正视矛盾**——把争执和不安也写进爱里：
   情书里不回避最近吵过的架、彼此的不安；先承认问题，再表达心意。
   只有甜言蜜语的情书，吵完架再看会显得虚假。

## 长期表达工程的做法

- **固定仪式感节点**：纪念日、生日、节日各一封，日常随灵感补充；
- **多样载体**：文字 + 手写照片 + 语音朗读（录音的仪式感远超文字）；
- **进度留档**：编号 + 日期 + 主题，写完在档案里登记一行；
- **写给未来的信**：偶尔写一封"一年后拆"的信，把期待封存。

## 纪念日的实操清单

1. 提前一个月在档案里立条目（纪念日最怕临期才发现）；
2. 三要素至少占两样：**礼物**（见 gifting.md）+ **仪式**（信/视频/旅行）+ **陪伴时间**；
3. 数字梗比奢侈品便宜且更戳人：在一起 100 天、500 天，
   "第 N 天"本身就是最好的礼物主题；
4. 用你的档案数据做惊喜：聊天年度报告、合照回顾、愿望清单兑现——
   "原来你都记得"比"这个很贵"更打动人。

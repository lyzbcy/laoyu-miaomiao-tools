# lyzbcy-douyin-comment

## Description
当回复抖音评论的时候使用此 skill。自动分类评论意图、生成个性化回复。回复格式：🦞 开头 + 回复内容 + ——来自周三涵 结尾。Custom skill for lyzbcy。

## Purpose
检查抖音新评论、私信、@消息，生成个性化回复并通知用户。

## Usage
当用户要求检查抖音评论或需要回复抖音评论时使用此技能。

## Process
1. 检查抖音平台是否有新的评论、私信或@消息
2. 分类评论意图（咨询、赞美、疑问、批评等）
3. 根据评论类型生成个性化回复
4. 按照指定格式组织回复：🦞 + 回复内容 + ——来自周三涵
5. 通知用户关于新评论的情况

## Reply Format
所有回复必须遵循以下格式：
- 开头：🦞
- 中间：个性化的回复内容
- 结尾：——来自周三涵

## Example
🦞 谢谢你的关注！很高兴你喜欢我的内容，我会继续分享更多有趣的视频！——来自周三涵

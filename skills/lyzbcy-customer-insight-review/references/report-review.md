# 客户洞察报告评审表

## 先从上期对应页锁定口径

对每个重点指标记录「客户问题 → 上期定义 → 本期来源 → 统计单位 → 范围与去重 → 图表及文字结论」。同时核对分子、分母、周期和数据覆盖。旧模板仅列结果时，用可用底稿复算一项历史数字，标明能够复现的部分。统一计算式只证明算式一致，上游采集和处理阶段也影响可比性。

基础会话记录量、按会话与日期去重的数量、筛选后的有效会话日、可解析记录数、话题标签数和情绪标签数分开计算。一条记录可含多条标签。模板会话环比使用基础记录量时，沿用该单位与上期基数；分析样本覆盖放在对应的分析页说明。

## 按客户问题组织内容

| 要回答什么 | 怎么做 | 最小验收证据 |
| --- | --- | --- |
| 本期会话如何变化，峰值何时出现 | 按模板定义复算规模及环比，按日或时段找高点。写明分母和日期归属 | 两期汇总、峰值所在切片、对得上日期的活动信息或脱敏原声 |
| 情绪怎样分布，正负向集中在哪 | 统计三类计数和占比，分别看数量与占比高点；给出每段的有效分母，百分点差最后舍入 | 三类情绪表、分母与排除规则、峰值日期及基数 |
| 话题大类和细类怎么变 | 大类写次数及环比；细类按当前分类比较集中点、升降与原声。核分类版本和映射，范围有限时写明主图选入规则 | 两月汇总、分类映射、主要变化可复算、有依据的解释 |
| 主要产品线及客户关注点 | 先统一型号、简称和别名。定义提及和讨论的计数单位，按需求分开汇总，再解释高频关注点和证据 | 型号归并规则、提及与关注点对应表、脱敏片段或可追溯切片 |

## 把数字写成客户能读懂的判断

- 每页写清当期最重要的发现，后面跟两项能支持它的数字或事实。图注交代分母、覆盖范围和影响解释的限制。
- 原因需要同一时间的业务事实、统计切片或脱敏原声支持。仅有时间重合时，描述为同期出现并写出后续验证所需证据。
- 重点图按已说明的样本或交集解读。声称全量排名时，先核完整分布和选入条件。
- 用户建议要说明适用业务场景和下一步动作。需要运营判断时按当前分工请熟悉业务的人核对。
- 定义、分母或映射一变，追踪正文、图表、备注、衍生比例和关联交付。最后回读实际交付件，核实客户看到的版本。

## 反馈如何回流

保留当期反馈的出处、适用条件和回归证据。可跨期使用的判断写进项目开工前检查。客户待确认的分类、打标和赋分继续按项目现行规则处理。需要向公开 Skill 回流时，把可复用做法抽象成无标识规则和独立合成案例。
